Unit-step complex-power integral bound and Hermitian Gram expansion of the dual column norm

Why do the off-diagonal twist estimate and the finite block mean-square inequality require both a slit-plane integral representation over unit steps and an explicit adjoint Gram expansion? Two elementary mechanisms convert pairwise character cancellation on a dyadic block (U, 2U] into a simultaneous mean-square bound across a finite family S. First, when summation by parts separates the bounded character partial sums from the complex weights n−z (Re z > 0), the discrete difference (n + 1)−z − n−z cannot be estimated by the real mean-value theorem alone because Im z may have modulus up to 2Q; instead, for any x > 0 the real segment [x, x + 1] lies strictly inside the open slit plane ℂ \ (−∞, 0], so integrating the holomorphic derivative −z t−z−1 and bounding |t−z−1| = t−Re z − 1 at the left endpoint x yields |x−z − (x + 1)−z| ≤ |z|x−Re z − 1, which is at most |z|/U for every integer n ≥ U ≥ 1. Second, passing from pairwise row correlations Gi,j = ∑n∈I vi(n) conj(vj(n)) to the squared row-output sum ∑i∈S |si|² requires no spectral decomposition: pairing the coefficient vector b with the dual column w(n) = ∑i∈S conj(si)vi(n) rewrites ∑i∈S |si|² as ∑n∈I b(n)w(n), and expanding ∑n∈I |w(n)|² into ∑i,j∈S conj(si)sjGi,j lets Hermitian symmetry |Gj,i| = |Gi,j| and 2|si||sj| ≤ |si|² + |sj|² collapse all off-diagonal couplings into the single row-sum budget Δ.

1. Slit-plane unit-step difference and finite Hermitian duality. Let x > 0 be a real number and let z ∈ ℂ, with complex powers defined by the principal branch on ℂ \ (−∞, 0]. Independently, let S and I be arbitrary finite index sets, let b : I → ℂ be a complex coefficient vector, and let v : S × I → ℂ, (i, n) ↦ vi(n), be a finite complex array. Define the row outputs si = ∑n∈I b(n)vi(n) for i ∈ S, the dual column w(n) = ∑i∈S conj(si)vi(n) for n ∈ I, and the Gram entries Gi,j = ∑n∈I vi(n) conj(vj(n)) for i, j ∈ S, and suppose Δ ≥ 0 is a real constant satisfying ∑j∈S |Gi,j| ≤ Δ for every i ∈ S (specialized in the block mean-square sieve to I = (U, 2U] ∩ ℕ and Δ = U + 8|S|Q³).

Proposition (Unit-step complex-power bound and finite Hermitian duality inequality).

(i) For every real x > 0, every z ∈ ℂ satisfies |∫xx+1 t−z−1 dt| ≤ ∫xx+1 t−Re z − 1 dt; whenever z ≠ 0, the real-variable map t ↦ t−z is continuously differentiable on [x, x + 1] with derivative −z t−z−1 and satisfies the integral identity below; and whenever Re z > 0, it satisfies the left-endpoint bound:

x−z − (x + 1)−z = z ∫xx+1 t−z−1 dt,   |x−z − (x + 1)−z| ≤ |z| x−Re z − 1.

In particular, for every integer U ≥ 1 and every integer n ≥ U, whenever Re z > 0 one has |(n + 1)−z − n−z| ≤ |z|/U.

(ii) For any finite index sets S and I and any Δ ≥ 0 with ∑j∈S |Gi,j| ≤ Δ for all i ∈ S, the Gram entries satisfy Gj,i = conj(Gi,j) and |Gj,i| = |Gi,j| for all i, j ∈ S, and the dual column norm and row outputs obey

∑n∈I |w(n)|² = ∑i∈S ∑j∈S conj(si) sj Gi,j ≤ Δ ∑i∈S |si|²,   ∑i∈S |si|² ≤ Δ ∑n∈I |b(n)|².

Proof. For (i), every t ∈ [x, x + 1] satisfies t ≥ x > 0, so its complex embedding has positive real part and lies in ℂ \ (−∞, 0]; for every z ∈ ℂ, |t−z−1| = t−Re z − 1 gives |∫xx+1 t−z−1 dt| ≤ ∫xx+1 t−Re z − 1 dt, and when z ≠ 0 the map t ↦ t−z has continuous derivative −z t−z−1; compare the partial-summation tail derivative. The fundamental theorem of calculus on [x, x + 1] gives (x + 1)−z − x−z = ∫xx+1 (−z t−z−1) dt, and negating both sides yields the integral identity. When Re z > 0 (hence z ≠ 0 and −Re z − 1 < 0), taking complex moduli gives |x−z − (x + 1)−z| ≤ |z| ∫xx+1 t−Re z − 1 dt ≤ |z|x−Re z − 1 since t−Re z − 1 ≤ x−Re z − 1 across [x, x + 1]. When n ≥ U ≥ 1 are integers, setting x = n ≥ U ≥ 1 gives n−Re z − 1 ≤ n−1 ≤ U−1 because Re z > 0, proving |(n + 1)−z − n−z| ≤ |z|/U (applied in particular to integers n > U at z = (ρχ − σ0) + conj(ρψ − σ0) on (U, 2U]).

For (ii), interchanging summation over i ∈ S and n ∈ I gives ∑i∈S |si|² = ∑i∈S si conj(si) = ∑n∈I b(n)w(n). Taking moduli and applying the finite Cauchy–Schwarz inequality on I yields (∑i∈S |si|²)² ≤ (∑n∈I |b(n)||w(n)|)² ≤ (∑n∈I |b(n)|²)(∑n∈I |w(n)|²). Expanding |w(n)|² = w(n) conj(w(n)) and interchanging summation over n ∈ I with i, j ∈ S gives ∑n∈I |w(n)|² = ∑i∈S ∑j∈S conj(si)sjGi,j ≤ ∑i∈S ∑j∈S |si||sj||Gi,j|. Using 2|si||sj| ≤ |si|² + |sj|² together with |Gj,i| = |Gi,j| reduces the double sum to ∑i∈S |si|² ∑j∈S |Gi,j| ≤ Δ ∑i∈S |si|². Substituting this bound gives (∑i∈S |si|²)² ≤ Δ (∑n∈I |b(n)|²)(∑i∈S |si|²); if ∑i∈S |si|² = 0 then 0 ≤ Δ ∑n∈I |b(n)|² holds since Δ ≥ 0, and if ∑i∈S |si|² > 0 then dividing both sides by that positive factor yields ∑i∈S |si|² ≤ Δ ∑n∈I |b(n)|².

Hermitian conjugation of the Gram matrix, Fubini interchange, and symmetric quadratic collapse

On [x, x + 1] with x > 0, every point satisfies t ≥ x > 0, so |t−z−1| = tRe(−z−1) = t−Re z − 1 is continuous and integrable on [x, x + 1]. Because Re z > 0 implies −Re z − 1 < 0, monotonicity of real powers with nonpositive exponent on (0, ∞) gives t−Re z − 1 ≤ x−Re z − 1 for all t ∈ [x, x + 1], whence ∫xx+1 t−Re z − 1 dt ≤ ((x + 1) − x)x−Re z − 1 = x−Re z − 1.

In the finite matrix identity, termwise complex conjugation over n ∈ I gives conj(Gi,j) = ∑n∈I conj(vi(n))vj(n) = ∑n∈I vj(n) conj(vi(n)) = Gj,i, so |Gj,i| = |conj(Gi,j)| = |Gi,j|. Next, for each n ∈ I, |w(n)|² = (∑i∈S conj(si)vi(n))(∑j∈S sj conj(vj(n))) = ∑i∈S ∑j∈S conj(si)sjvi(n) conj(vj(n)); summing over n ∈ I, interchanging the outer sum over n with the double sum over i, j ∈ S, and factoring conj(si)sj out of ∑n∈I vi(n) conj(vj(n)) produces ∑i∈S ∑j∈S conj(si)sjGi,j. Finally, since (|si| − |sj|)² ≥ 0 gives |si||sj| ≤ (|si|² + |sj|²)/2 and |Gi,j| ≥ 0, splitting the double sum yields ∑i∈S ∑j∈S |si||sj||Gi,j| ≤ (1/2) ∑i∈S |si|² ∑j∈S |Gi,j| + (1/2) ∑j∈S |sj|² ∑i∈S |Gi,j|. Substituting |Gi,j| = |Gj,i| into the second sum and exchanging the dummy indices (i, j) identifies the two halves, giving ∑i∈S |si|² ∑j∈S |Gi,j| ≤ ∑i∈S |si|² · Δ = Δ ∑i∈S |si|².

Prime-power divisor majorant, dyadic coefficient-square monotone bound, and explicit binary-logarithm absorption thresholds

Why does a single explicit constant C = A2K dominate the squared Möbius-convolution weights on every dyadic block (U, 2U], and why can one threshold Q0 ≥ 20 simultaneously validate both the off-diagonal subtraction condition and the final Q1/4 zero-density bound? Two quantitative trade-offs drive these estimates. First, comparing the divisor product τ(n) = ∏p|n (vp(n) + 1) against nε = ∏p|n (pε)vp(n) for any ε > 0, every prime factor large enough that pε ≥ 2 already satisfies k + 1 ≤ 2k ≤ (pε)k with prefactor 1; only primes below the finite cutoff K = ⌈21/ε⌉ require a compensating factor, and for each such prime p ≥ 2 the linear-to-exponential bound k + 1 ≤ A exp(εk log 2) ≤ A(pε)k with A = max(1, 1/(ε log 2)) costs at most one factor A across at most K primes, yielding τ(n) ≤ AKnε. Second, on the dyadic detector windows X = ⌈Q⌉, Y = X⁴, J = 8(⌊log2 X⌋ + 1), and N = 2J, the number of blocks grows only logarithmically (J ≤ 32 log Q for Q ≥ 20): on the shortest block U ≥ Y ≥ Q⁴, the power saving Q³U−197/200 ≤ Q−47/50 overwhelms 64C J², while at the terminal scale Y N ≤ 220Q12 the exponent (Y N)3/200 ≤ 23/10Q9/50 leaves Q7/100 to absorb J³.

1. Prime-power divisor bound, dyadic square sum, and simultaneous window thresholds. For any real exponent ε > 0, define A = max(1, 1/(ε log 2)) ≥ 1, K = ⌈21/ε⌉ ∈ ℕ, and D = AK ≥ 1, writing τ(n) for the number of positive divisors of an integer n ≥ 1 and vp(n) for the exponent of each prime divisor p of n.
