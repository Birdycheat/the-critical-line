Counting the rows and lifting each one

The row count has to answer two questions. How many row classes pass the lattice test? For each such row, is there a corner with the required denominator that makes the matrix unitary? Fix the middle unitary block g of size m and length h. The lattice calculation supplies integral matrices U,V,C with gC integral, (U + Vg)C = I and v(det C) = h. Here v is additive with v(ϖ) = 1. At row level e, set A = ϖeC. The admissible rows form Λ = {r ∈ Lm : rA ∈ 𝒪m}, and two rows have the same class when their difference is integral. Write A = P diag(ϖd₁,…,ϖdₘ) Q with P,Q and their inverses integral. The diagonal matrix is integral because it equals P−1AQ−1, so every dᵢ ≥ 0. Changing r to rP preserves the integral row lattice and removes P from the calculation. Multiplying on the right by Q preserves integrality in both directions. The ith coordinate can now range over ϖ−dᵢ𝒪/𝒪. This quotient has (q²)dᵢ elements, since each digit ranges over the extension residue field. Multiplying the coordinate counts and taking determinants gives

[Λ : 𝒪m] = (q²)∑ dᵢ = (q²)v(det A) = q2(h+me).

Raising the row level by one allows one additional residue-field digit in each of the m coordinates. The factor (q²)h is already present at level zero. How to choose the corner

For a representative r ∈ Λ, form its paired column b by bᵢ = −σ(rm+1−i), using indices 1 through m. Put b₁ = CVg b and b₂ = CU b, where these subscripts now label two whole vectors. They add to b since C(U + Vg) = I. The lattice duality calculation gives ϖeb₁ and ϖeg b₂ integral. To see where g enters, expand r = (rC)U + ((rC)V)g. Negating, conjugating and reversing coordinates sends this to b = x + g−1y with ϖex and ϖey integral, by unitarity of g. Thus b₁ = (I − CU)x + CVy and g b₂ = gCUx + (I − gCV)y. Write ⟨x,y⟩ = ∑ᵢ σ(xᵢ)ym+1−i for the Hermitian form and Tr(z) = z + σ(z). Choose an integral τ with Tr(τ) = 1. For example, τ = σ(z)/(σ(z) − z) works whenever z is integral and its difference from its conjugate is a unit. Put

s = ⟨b₁,b₁⟩ − ⟨b₂,b₂⟩,   c = r · b₁ + τs.

The two norms make s fixed by σ. Since r · b₁ = −⟨b,b₁⟩, the trace of c is −⟨b,b₁⟩ − ⟨b₁,b⟩ + s = −⟨b,b⟩ = r · b. This is precisely the unitary relation on the upper-right entry of the unipotent matrix with row r and column b. Its corrected corner is c − r · b₁ = τs. Multiplying a Hermitian norm by ϖ2e scales each of its two arguments by ϖe. For the second norm use ⟨b₂,b₂⟩ = ⟨gb₂,gb₂⟩. Both scaled norms are integral. Consequently the corrected corner passes the test at every f ≥ 2e. The ball count takes e = max(a,0) + ⌊j/2⌋ and f = 2 max(a,0) + j, so every row in its index actually lifts. A row that uses both denominator powers. Over ℚ₂(ω) with ω² + ω + 1 = 0, take m = 1, g = C = U = 1 and V = 0. With a = 1 and j = 0 the levels are e = 1, f = 2. The four row classes in ½𝒪/𝒪 are represented by 0, 1/2, ω/2 and (1 + ω)/2. Choose r = 1/2. Then b = −1/2, b₁ = 0, b₂ = b, and s = −1/4. Taking τ = −ω gives Tr(τ) = 1 and c = ω/4. Indeed 4c is integral and Tr(c) = −1/4. At the hypothetical smaller level f = 1, any lift of this row would need 2c integral while Tr(2c) = −1/2. The trace of an integral element is integral, so this particular row cannot lift at that level.
