How does density act on an L² class? Choose a measurable, B-invariant representative F of a common class. For each edge group E the finite coset average of F is pointwise E-invariant. Its difference from F has squared norm zero on the cover, so the two agree almost everywhere there. Both are B-invariant, hence the exceptional set is Haar-null in the whole group by the fundamental-domain formula. Left translation preserves null sets. It follows for each γ ∈ E that F(γx) = F(x) for almost every x. The set of γ satisfying this condition is a subgroup, since a translated null set is null. Why does invariance extend to every translation?

Fix a Borel set U of real values and let T = F−1(U). The translations preserving T up to a null set form a closed set. To see this, take gₙ → g. On a compact test region C, the images gₙC and gC eventually lie in one compact set L₀. The set T ∩ L₀ has finite measure. The measure of the symmetric difference between its two translation preimages tends to zero. If each gₙ preserves T almost everywhere, then g does so on C. A countable compact cover gives the assertion everywhere up to Haar measure zero. Density now gives invariance for every fixed g. Such a set has measure zero or has null complement. Indeed, if T has positive measure, Fubini gives a point a ∈ T such that ba ∈ T for almost every b. Right multiplication by a preserves the Haar null sets, so the complement of T is null. Applying this argument to inverse images of a countable family separating real values shows that F is constant almost everywhere.
