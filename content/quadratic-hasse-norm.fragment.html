Fundamental equality and Tate cohomology vanishing for cyclic idèle class groups

Why does the vanishing of the minus-one cyclic Tate cohomology group Ĥ−1(G, CL) follow purely from comparing two bounds on the global idèle-class norm index [CK : NL/K(CL)], and why is this single vanishing statement the exact cohomological obstruction behind the cyclic and quadratic Hasse norm theorems? For a cyclic Galois extension L/K of number fields with Galois group G = ⟨σ⟩, the base-change map ι : CK ↪ CL identifies CK with the G-invariant subgroup CLG and sends the idèle-class norm NL/K(CL) onto the cyclic Galois norm image NG(CL), giving an isomorphism CK/NL/K(CL) ≅ Ĥ0(G, CL). Because the Herbrand quotient h(CL) = |Ĥ0(G, CL)| / |Ĥ−1(G, CL)| equals the field degree [L : K] with finite nonzero denominator, the norm index is literally [L : K] times |Ĥ−1(G, CL)|. That immediately yields the first inequality [L : K] ≤ [CK : NL/K(CL)], with equality if and only if |Ĥ−1(G, CL)| = 1. The second inequality supplies the opposite bound [CK : NL/K(CL)] ≤ [L : K], locking the norm index to [L : K] and forcing Ĥ−1(G, CL) to be trivial: every idèle class in CL of norm 1 is a Galois coboundary σ(d)/d.

1. Cyclic Tate cohomology of idèle classes and the class-field axiom. Let K and L be number fields with L/K a finite Galois extension whose Galois group G = Gal(L/K) is cyclic, generated by σ ∈ G. Let 𝕀K and 𝕀L denote the idèle groups of K and L, with idèle class groups CK = 𝕀K/K× and CL = 𝕀L/L×, canonical base-change homomorphism ι : CK → CL, and idèle-class norm NL/K : CL → CK. Viewing CL as a G-module (written additively in cohomology, with multiplicative notation c ↦ σ(c)/c for σ − 1 and c ↦ ∏g∈G g(c) for the cyclic norm NG), define the cyclic Tate cohomology groups Ĥ0(G, CL) = ker(σ − 1)/im(NG) and Ĥ−1(G, CL) = ker(NG)/im(σ − 1), and the Herbrand quotient h(CL) = |Ĥ0(G, CL)| / |Ĥ−1(G, CL)| whenever both groups are finite.

Proposition (Fundamental equality and vanishing of minus-one cyclic Tate cohomology).

(i) The base-change homomorphism induces a group isomorphism CK/NL/K(CL) ≅ Ĥ0(G, CL), so |Ĥ0(G, CL)| = [CK : NL/K(CL)]. From the Herbrand quotient h(CL) = [L : K], both cyclic Tate groups are finite (hence |Ĥ−1(G, CL)| ≠ 0), and

|Ĥ0(G, CL)| = [CK : NL/K(CL)] = [L : K] · |Ĥ−1(G, CL)|,   [L : K] ≤ [CK : NL/K(CL)].

(ii) Combining this first inequality with the second inequality [CK : NL/K(CL)] ≤ [L : K] gives the fundamental equality and the cyclic class-field axiom:

[CK : NL/K(CL)] = [L : K],   |Ĥ0(G, CL)| = [L : K],   |Ĥ−1(G, CL)| = 1.

In particular, Ĥ−1(G, CL) is trivial: every idèle class c ∈ CL with NG(c) = 1 lies in im(σ − 1), that is, c = σ(d)/d for some d ∈ CL.

Proof. For (i), let Φ : CK → Ĥ0(G, CL) send c ∈ CK to the coset of ι(c) modulo im(NG). Since the Galois action on CL fixes the image of ι, σ(ι(c)) = ι(c), so ι(c) ∈ ker(σ − 1) and Φ is a well-defined homomorphism. To see that Φ is surjective, take any coset represented by y ∈ ker(σ − 1); because σ generates G, σ(y) = y implies g(y) = y for every g ∈ G, so Galois descent for idèle classes yields c ∈ CK with ι(c) = y, whence Φ(c) is the given coset. To compute ker(Φ), observe that for every d ∈ CL the cyclic Galois norm satisfies NG(d) = ∏g∈G g(d) = ι(NL/K(d)). Therefore c ∈ ker(Φ) if and only if ι(c) = ι(NL/K(d)) for some d ∈ CL; since ι : CK → CL is injective, this holds if and only if c ∈ NL/K(CL). By the first isomorphism theorem, CK/NL/K(CL) ≅ Ĥ0(G, CL), giving |Ĥ0(G, CL)| = [CK : NL/K(CL)].

Next, the Herbrand quotient of the cyclic G-module CL is well-defined (both Ĥ0(G, CL) and Ĥ−1(G, CL) are finite, so |Ĥ−1(G, CL)| ≥ 1) and satisfies |Ĥ0(G, CL)| / |Ĥ−1(G, CL)| = [L : K] in ℚ. Clearing the nonzero denominator and substituting |Ĥ0(G, CL)| = [CK : NL/K(CL)] gives the exact natural-number identity [CK : NL/K(CL)] = [L : K] · |Ĥ−1(G, CL)|. Because |Ĥ−1(G, CL)| ≥ 1 and [L : K] ≥ 1, this yields both the first inequality [L : K] ≤ [CK : NL/K(CL)] and finiteness of the norm index.

For (ii), the second inequality states that the cardinality of the quotient CK/NL/K(CL) is at most [L : K], so [CK : NL/K(CL)] ≤ [L : K]. Antisymmetry with the first inequality establishes the fundamental equality [CK : NL/K(CL)] = [L : K], and hence |Ĥ0(G, CL)| = [L : K]. Substituting [CK : NL/K(CL)] = [L : K] into [CK : NL/K(CL)] = [L : K] · |Ĥ−1(G, CL)| gives [L : K] · 1 = [L : K] · |Ĥ−1(G, CL)|; cancelling [L : K] > 0 forces |Ĥ−1(G, CL)| = 1. A group of cardinality 1 has only the identity element, so every c ∈ ker(NG) represents 0 in ker(NG)/im(σ − 1) and therefore satisfies c = σ(d)/d for some d ∈ CL.

Role of the Herbrand quotient, origin of the second inequality, and a finite-module contrast

For any finite cyclic group G = ⟨σ⟩ and finite G-module A, the exact sequences for σ − 1 and NG force |Ĥ0(G, A)| = |Ĥ−1(G, A)|, so h(A) = 1. For example, with G = ⟨σ⟩ of order 2 acting on A = ℤ/4ℤ by σ(a) = −a, one has NG(a) = a − a = 0 and (σ − 1)(a) = −2a; hence ker(σ − 1) = {0, 2} and im(NG) = {0} give |Ĥ0| = 2, while ker(NG) = ℤ/4ℤ and im(σ − 1) = {0, 2} give |Ĥ−1| = 2, so h(A) = 2/2 = 1. By contrast, CL is infinite; choosing a large finite set of places S containing all ramified places and generators of Cl(L) expresses CL as the quotient of the S-idèle group 𝕀L,S by the S-unit group 𝒪L,S×, whose Herbrand quotients are respectively ∏v∈S [Lw : Kv] (with w any place of L over v, independent of the choice since L/K is Galois) and (∏v∈S [Lw : Kv])/[L : K] (from Dirichlet’s S-unit lattice). Taking the ratio cancels all local factors and leaves h(CL) = [L : K].

In the second inequality, the cyclic global norm bound [CK : NL/K(CL)] ≤ [L : K] is deduced from the first inequality itself by strong induction on [L : K]: reducing along a prime-index subgroup reduces to prime-degree cyclic extensions, and adjoining primitive p-th roots of unity reduces to Kummer extensions, where the first inequality applied to auxiliary fields yields the upper bound on the norm index.

Cyclic and quadratic Hasse norm theorems and everywhere-local norm criteria for CM ideals

When does being a local norm at every place of a number field K guarantee that an element x ∈ K× is a global norm from an extension L/K, and why does a totally positive generator a of a conjugate ideal product I · c(I) = (a) in a finitely unramified CM extension K/K+ satisfy those local conditions automatically, supplying the global norm step in the dyadic signature injection? For any cyclic Galois extension L/K, the local-to-global passage factors into two clean steps. First, local norms at every finite and infinite place assemble into an idèle j ∈ 𝕀L with NL/K(j) = diag(x), because all but finitely many places are unramified and at every unramified finite place the local norm maps local integer units surjectively onto 𝒪Kv×. Second, the idèle class [j] ∈ CL has cyclic Galois norm 1 because diag(x) is principal; by Tate cohomology vanishing, [j] = [σ(e)/e] for an idèle e ∈ 𝕀L, so (σ(e)/e)−1j is a principal idèle diag(a) with a ∈ L×, and G-invariance of the idèle norm gives NL/K(a) = x. Since every quadratic extension of number fields is cyclic Galois, this applies immediately to any CM extension K/K+. For an ideal I ⊆ 𝒪K with I · c(I) = (a) and a = x ∈ (K+)× totally positive, Dedekind approximation at each finite place v of K+ picks b ∈ I whose norm n = b c(b) differs from x by a v-adic unit t, which is a local norm by unramifiedness; at each infinite place of K+ (necessarily real), total positivity supplies a positive real d-th root whose local norm is x.

1. Cyclic and quadratic local-to-global norm equivalence and CM local norm criteria. Let K and L be number fields with L/K a finite extension, diag : K× ↪ 𝕀K the diagonal embedding, and NL/K : 𝕀L → 𝕀K the idèle norm, whose component at a finite place v (resp. an infinite place v) of K is the product of local field norms Nv : ∏w∣v Lw× → Kv×. Write xv for the image of diag(x) at the place v. For a CM number field K, write K+ for its maximal totally real subfield ([K : K+] = 2) and c for complex conjugation on K (and its restriction to 𝒪K).

Proposition (Cyclic and quadratic Hasse norm theorems and everywhere-local norm criteria in CM extensions).

(i) Suppose L/K is Galois with cyclic Galois group G = Gal(L/K) (in particular, this holds automatically whenever [L : K] = 2). For every x ∈ K× (equivalently, every nonzero x ∈ K),

x ∈ NL/K(L×)   ⟺   diag(x) ∈ NL/K(𝕀L)   ⟺   (∀ v finite, xv ∈ im Nv) ∧ (∀ v infinite, xv ∈ im Nv).

(ii) Let K be a CM number field such that every finite place of K is unramified over K+. Let I ⊆ 𝒪K be a nonzero integral ideal, a ∈ 𝒪K, and x ∈ (K+)× such that a = x in K, I · c(I) = (a), and Re φ(a) > 0 for every complex embedding φ : K → ℂ. Then xv ∈ im Nv at every finite place v and every infinite place v of K+, and consequently

I · c(I) = (a),   a = x ∈ (K+)×,   Re φ(a) > 0 (∀ φ : K → ℂ)   ⟹   ∃ β ∈ K×,   NK/K+(β) = x.

Proof. For the first equivalence in (i), if x = NL/K(a) with a ∈ L×, then diag(x) = NL/K(diag(a)) ∈ NL/K(𝕀L). Conversely, suppose diag(x) = NL/K(j) for some idèle j ∈ 𝕀L, and pick a generator σ of the cyclic group G = Gal(L/K). Let y = [j] ∈ CL be the idèle class of j. Because diag(x) is principal, its idèle class in CK is 1, so the cyclic Galois norm satisfies

NG(y) = ∏g∈G g([j]) = ι(NL/K([j])) = ι([NL/K(j)]) = ι([diag(x)]) = 1.

Thus y ∈ ker(NG). By vanishing of minus-one cyclic Tate cohomology, |Ĥ−1(G, CL)| = 1, so Ĥ−1(G, CL) has only one element and the class of y in ker(NG)/im(σ − 1) is trivial. Hence y = σ(d)/d for some d ∈ CL. Choosing a lift e ∈ 𝕀L with [e] = d gives [j] = [σ(e)/e] in CL = 𝕀L/L×, so there exists a ∈ L× whose diagonal idèle satisfies diag(a) = (σ(e)/e)−1 · j. Applying the idèle norm NL/K, which is invariant under G (so NL/K(σ(e)/e) = NL/K(σ(e))/NL/K(e) = 1), yields

diag(NL/K(a)) = NL/K(diag(a)) = NL/K((σ(e)/e)−1) · NL/K(j) = 1 · diag(x) = diag(x).

Since diag : K× ↪ 𝕀K is injective, NL/K(a) = x. The second equivalence in (i) follows from local-to-idelic norm assembly (detailed below), and when [L : K] = 2 (in characteristic 0), L/K is automatically Galois with cyclic Galois group of order 2.

For (ii), fix first any finite place v of K+ (a nonzero prime ideal of 𝒪K+), choose a prime ideal w of 𝒪K lying over v, and set P = v𝒪K. Then P is nonzero and fixed by complex conjugation c (since c fixes 𝒪K+). By Dedekind approximation in 𝒪K (detailed below), since I · c(I) = (a) and c(P) = P, there exist b, t ∈ 𝒪K such that b c(b) = a t and t ∉ w (for every prime ideal w containing P). Since t ∉ w, we have t ≠ 0, hence b ≠ 0 (as a = x ≠ 0). Because Gal(K/K+) = {1, c}, the element n = NK/K+(b) ∈ (K+)× satisfies n = b c(b) = a t in K, so n x−1 = t in K. Because t ∉ w, its multiplicative w-adic valuation equals 1 (so t is a w-adic unit); as w lies over v with positive ramification index, the multiplicative v-adic valuation of n x−1 is also 1, so (n x−1)v lies in the local integer unit group 𝒪Kv+×. Since w is unramified over v (ramification index 1), the local norm map from the integer units over v surjects onto 𝒪Kv+×, proving (n x−1)v ∈ im Nv. Meanwhile n = NK/K+(b) is a global norm, hence nv ∈ im Nv; multiplying (n x−1)v−1 · nv = xv inside the local norm subgroup shows xv ∈ im Nv.

Next fix any infinite place v of K+, and choose an infinite place W of K lying over v. Because K+ is totally real, v is a real place, giving a canonical ring isomorphism e : Kv+ ≅ ℝ. The complex embedding of W restricts to v (up to complex conjugation), so total positivity Re φ(x) > 0 implies e(xv) > 0 in ℝ. Let d = [KW : Kv+] ∈ {1, 2} be the local archimedean degree (equal to 2 since K is totally complex), and define r = e−1(e(xv)1/d) ∈ Kv+; then rd = xv ≠ 0, so the image of r in KW is nonzero. Setting the component at W equal to r and all other components over v equal to 1 produces an element of ∏W′∣v KW′× whose local norm is NKW/Kv+(r) = rd = xv, proving xv ∈ im Nv. Applying (i) to the quadratic extension K/K+ yields β ∈ K× with NK/K+(β) = x.

Local-to-idelic assembly via unramified unit norms, the Dedekind ideal-approximation step, and a quadratic illustration

For the second equivalence in (i), any idèle norm NL/K(j) = diag(x) restricts at every place v to a local norm. Conversely, suppose xv ∈ im Nv for every finite and infinite place v. Because the different ideal of the finite separable extension L/K is nonzero, it has only finitely many prime factors, so all but finitely many finite places w of L have ramification index 1 over K. At any finite place v of K admitting an unramified place w of L over it, every local unit u ∈ 𝒪Kv× is the local norm of an integer unit y ∈ 𝒪Lw× (placed at w, with 1 at every other place w′ over v), so Nv maps ∏w′∣v 𝒪Lw′× surjectively onto 𝒪Kv×. Because xv ∈ 𝒪Kv× for all but finitely many finite places v, the local preimages over v can be chosen inside the integer units at all but finitely many finite places, assembling into an idèle j ∈ 𝕀L with NL/K(j) = diag(x).

For the Dedekind approximation step in (ii), let R = 𝒪K, with nonzero ideals P, I, nonzero a ∈ R, c(P) = P, and I · c(I) = (a). Since I P ⊆ I and I P ≠ 0 in the Dedekind domain R, there exists b ∈ I such that I P + (b) = I. Because (b) ⊆ I, factorization of ideals gives an integral ideal J with (b) = I J, so I(P + J) = I; cancelling the nonzero ideal I yields P + J = R, and applying the ring automorphism c gives P + c(J) = R. Multiplying (b) = I J by (c(b)) = c(I)c(J) yields (b c(b)) = (I c(I))(J c(J)) = (a)(J c(J)) ⊆ (a), so b c(b) = a t for some t ∈ R. Cancelling (a) ≠ 0 gives (t) = J c(J). If a prime ideal w containing P contained t, then J c(J) ⊆ w would force J ⊆ w or c(J) ⊆ w, contradicting P + J = R or P + c(J) = R; hence t ∉ w.

As a concrete illustration over K+ = ℚ with K = ℚ(i), take x = 5 and I = (2 + i), so I · c(I) = (5). At the real place, x = 5 > 0 has the positive square root r = √5 ∈ ℝ with Nℂ/ℝ(√5) = 5; at every unramified odd prime p ≠ 5, 5 is a p-adic unit and hence a local norm, and at p = 5 (which splits) and p = 2 (where 5 ≡ 1 mod 4), 5 = Nℚ(i)/ℚ(2 + i) is already a global norm. By contrast, x = −5 fails the archimedean positivity condition (Re(−5) < 0) and is not a norm from ℚ(i). In the dyadic cyclotomic layers L = ℚ(ζf 2n) with odd f > 1 and n ≥ 2 used in the dyadic signature injection, L/L+ is unramified at every finite place (including places above 2), so part (ii) supplies the global norm β ∈ L× directly.
