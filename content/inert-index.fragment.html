Why one more corner digit gives q choices

Fix an admissible row in a unitary cell. Its paired column is then fixed, and the upper-right entry c satisfies c + σ(c) = row · column. Two lifts of the same row therefore differ in the corner by an element of trace zero. Subtracting their corrected corner conditions cancels the row–column term and says that ϖf times this difference is integral. For the valuation ring 𝒪, put T = {u ∈ 𝒪 : σ(u) = −u}. After choosing one lift, all the allowable differences form ϖ−fT. An integral change of corner contributes an element of T, so the fiber over this row class has size [ϖ−fT : T]. The residue field 𝒪/ϖ𝒪 has q² elements. To compute the number of its digits available in a trace-zero corner, choose x ∈ 𝒪 such that Δ = σ(x) − x is a unit. Its existence is part of the unramified involution hypotheses. Every y ∈ 𝒪 has two integral trace-zero coordinates

u = σ(x)y − xσ(y),   w = σ(y) − y,   y = (u + xw)/Δ.

Conversely, start from any u,w ∈ T and use the last formula for y. Since σ(Δ) = −Δ, one gets σ(y) = (u + σ(x)w)/Δ, which recovers w and then u. Thus this is an additive isomorphism T × T ≃ 𝒪. It commutes with multiplication by ϖ because σ fixes ϖ. Reducing both sides modulo ϖ gives [T : ϖT]² = |𝒪/ϖ𝒪| = q². In particular every corner digit has q choices. This proof works even in residue characteristic two because its only scalar division is by the unit Δ. Four corners at level two. Take L = ℚ₂(ω), where ω² + ω + 1 = 0. This polynomial is irreducible and separable modulo 2, giving the unramified quadratic extension with 𝒪 = ℤ₂[ω], ϖ = 2 and q = 2. Here σ(ω) = −1 − ω. The trace of a + bω is 2a − b, so T = ℤ₂η with η = 1 + 2ω. Taking x = ω gives Δ = −η, a unit. With row zero the column and its correction vanish. At f = 2 the corners have representatives 0, η/4, η/2 and 3η/4. Each has integral quadruple and trace zero. Two representatives agree modulo T precisely when their numerators in units of η agree modulo 4. This checks the local index even in residue characteristic two. In the global chain every dyadic place outside the exceptional set must split. This inert dyadic example therefore illustrates the local counting lemma only.
