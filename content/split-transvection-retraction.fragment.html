1. Fiberwise double-complex slice exactness and typed split-simplex chain isomorphism. Let V and W be sets with augmented sequence boundaries ∂V on ℤ[List(V)] and ∂W on ℤ[List(W)]. For any relation 𝒟 ⊆ List(V) × List(W) and integers a, b ∈ ℕ, let Da,b(𝒟) ⊆ ℤ[List(V) × List(W)] denote the subgroup of finite ℤ-linear combinations x = ∑(l,w) x(l, w)⟨(l, w)⟩ supported on pairs (l, w) ∈ 𝒟 with |l| = a and |w| = b, with horizontal differential ∂h(⟨(l, w)⟩) = ∑i=0|l|−1 (−1)i⟨(l(i), w)⟩ and vertical differential ∂v(⟨(l, w)⟩) = ∑k=0|w|−1 (−1)k⟨(l, w(k))⟩ (written h and v in the split double complex), column fibers Col𝒟(l) = {w ∈ List(W) : (l, w) ∈ 𝒟}, and row fibers Row𝒟(w) = {l ∈ List(V) : (l, w) ∈ 𝒟}. Over a commutative ring R with identity and n ∈ ℕ, let 𝒮n ⊆ List(Rn × Rn) be the set of split lists [(v0, λ0), …, (vp−1, λp−1)] satisfying λi · vj = δi,j (0 ≤ i, j < p), and for each p ∈ ℕ set 𝒮n,p = {l ∈ 𝒮n : |l| = p} with inclusion ηp : 𝒮n,p ↪ List(Rn × Rn), ℤ-linear extension Φp : ℤ[𝒮n,p] → ℤ[List(Rn × Rn)] sending ⟨σ⟩ to ⟨ηp(σ)⟩, and alternating face differential dp : ℤ[𝒮n,p+1] → ℤ[𝒮n,p] sending ⟨σ⟩ to ∑i=0p (−1)i⟨∂i(σ)⟩, where ∂i(σ) ∈ 𝒮n,p deletes the i-th pair of σ.

Proposition (Double-complex column and row slice exactness and typed split-chain isomorphism).

(i) Let 𝒟 ⊆ List(V) × List(W) and a, b ∈ ℕ. For any x ∈ Da,b(𝒟), setting T1 = {l ∈ List(V) : ∃ w, x(l, w) ≠ 0}, T2 = {w ∈ List(W) : ∃ l, x(l, w) ≠ 0}, gl = ∑w x(l, w)⟨w⟩, ιl(⟨w⟩) = ⟨(l, w)⟩, pw(x) = ∑l x(l, w)⟨l⟩, and jw(⟨l⟩) = ⟨(l, w)⟩ yields

x = ∑l∈T1 ιl(gl) = ∑w∈T2 jw(pw(x)),   ∂v(ιl(gl)) = ιl(∂Wgl),   ∂h(jw(pw(x))) = jw(∂Vpw(x)).

If Col𝒟(l) is exact at length b for every l ∈ List(V) with |l| = a and Col𝒟(l) ≠ ∅, then every x ∈ Da,b(𝒟) with ∂vx = 0 equals ∂vy for some y ∈ Da,b+1(𝒟). Symmetrically, if Row𝒟(w) is exact at length a for every w ∈ List(W) with |w| = b and Row𝒟(w) ≠ ∅, then every x ∈ Da,b(𝒟) with ∂hx = 0 equals ∂hy for some y ∈ Da+1,b(𝒟).

(ii) For all n, p ∈ ℕ, Φp is injective with image Cp(𝒮n), satisfies Φp(dp(c)) = ∂(Φp+1(c)) for all c ∈ ℤ[𝒮n,p+1], and satisfies dp(dp+1(c′)) = 0 for all c′ ∈ ℤ[𝒮n,p+2]. Exactness of 𝒮n at length 0 implies surjectivity of d0 : ℤ[𝒮n,1] → ℤ[𝒮n,0], and exactness of 𝒮n at length p + 1 implies ker(dp) = im(dp+1) in

Φp(ℤ[𝒮n,p]) = Cp(𝒮n),   Φp(dp(c)) = ∂(Φp+1(c)),   ⋯ ⟶ ℤ[𝒮n,2] ⟶d1 ℤ[𝒮n,1] ⟶d0 ℤ[𝒮n,0] ⟶ 0.

Proof. For (i), let x ∈ Da,b(𝒟) satisfy ∂vx = 0. Finiteness of supp(x) makes T1 finite, and every l ∈ T1 satisfies |l| = a, Col𝒟(l) ≠ ∅, and gl ∈ Cb(Col𝒟(l)), with x = ∑l∈T1 ιl(gl). On basis generators, ∂v(ιl(⟨w⟩)) = ∂v(⟨(l, w)⟩) = ιl(∂W⟨w⟩), so 0 = ∂vx = ∑l∈T1 ιl(∂Wgl). Because supp(ιl(∂Wgl)) ⊆ {l} × List(W) are pairwise disjoint across distinct l ∈ T1, ∂Wgl = 0 for every l ∈ T1. Choosing yl ∈ Cb+1(Col𝒟(l)) with ∂Wyl = gl and setting y = ∑l∈T1 ιl(yl) ∈ Da,b+1(𝒟) gives ∂vy = ∑l∈T1 ιl(∂Wyl) = x. Exchanging the two coordinates over the finite set T2 with ∂h(jw(c)) = jw(∂Vc) proves the horizontal claim.

For (ii), injectivity of ηp makes Φp injective with image ℤ[{⟨l⟩ : l ∈ 𝒮n, |l| = p}] = Cp(𝒮n). For each σ ∈ 𝒮n,p+1, ηp(∂i(σ)) deletes the i-th entry of ηp+1(σ) (0 ≤ i ≤ p), giving Φp(dp(⟨σ⟩)) = ∂(Φp+1(⟨σ⟩)) and hence Φp(dp(c)) = ∂(Φp+1(c)) by linearity. Using ∂(∂u) = 0 from the prepending cone identity gives Φp(dp(dp+1(c′))) = ∂(∂(Φp+2(c′))) = 0, so dp(dp+1(c′)) = 0 by injectivity of Φp, which in particular implies im(dp+1) ⊆ ker(dp). Finally, for c0 ∈ ℤ[𝒮n,0], Φ0(c0) ∈ C0(𝒮n) = ℤ[⟨[]⟩] satisfies ∂(Φ0(c0)) = 0, so exactness at length 0 yields B = Φ1(B0) ∈ C1(𝒮n) with Φ0(d0(B0)) = ∂B = Φ0(c0), hence d0(B0) = c0; and for c0 ∈ ker(dp) ⊆ ℤ[𝒮n,p+1], ∂(Φp+1(c0)) = Φp(dp(c0)) = 0, so exactness at length p + 1 yields B = Φp+2(B0) ∈ Cp+2(𝒮n) with Φp+1(dp+1(B0)) = ∂B = Φp+1(c0), hence dp+1(B0) = c0 and ker(dp) = im(dp+1).

Disjoint support evaluation on double-complex fibers, horizontal row symmetry, and basis-simplex verification of the face differential

For fixed l ∈ List(V) and any chain c ∈ ℤ[List(W)], evaluating ιl(c) at (l′, u) ∈ List(V) × List(W) gives c(u) when l′ = l and 0 when l′ ≠ l. Consequently, for any l0 ∈ T1 and u ∈ List(W), (∑l∈T1 ιl(∂Wgl))(l0, u) = (∂Wgl0)(u); thus ∂vx = 0 implies (∂Wgl0)(u) = 0 for every u ∈ List(W). Moreover, each yl ∈ Cb+1(Col𝒟(l)) is supported on lists w′ ∈ Col𝒟(l) of length b + 1, so every pair in supp(ιl(yl)) has the form (l, w′) ∈ 𝒟 with |l| = a and |w′| = b + 1, confirming y = ∑l∈T1 ιl(yl) ∈ Da,b+1(𝒟) because Da,b+1(𝒟) is closed under finite sums.

In the horizontal mirror, for fixed w ∈ List(W) and c ∈ ℤ[List(V)], (jw(c))(u, w′) equals c(u) when w′ = w and 0 when w′ ≠ w, and ∂h(jw(⟨l⟩)) = ∑i=0|l|−1 (−1)i⟨(l(i), w)⟩ = jw(∂V⟨l⟩); evaluating ∂hx = ∑w∈T2 jw(∂Vpw(x)) = 0 at (u, w0) gives (∂Vpw0(x))(u) = 0 for each w0 ∈ T2, and summing jw(zw) over zw ∈ Ca+1(Row𝒟(w)) produces y ∈ Da+1,b(𝒟) with ∂hy = x. Finally, for any σ = [(v0, λ0), …, (vp, λp)] ∈ 𝒮n,p+1, its length is p + 1 ≥ 1 and ∂i(σ) omits the i-th pair while preserving λa · vb = δa,b on the remaining p pairs, so Φp(dp(⟨σ⟩)) = ∑i=0p (−1)i⟨ηp(∂i(σ))⟩ = ∂(⟨ηp+1(σ)⟩).
