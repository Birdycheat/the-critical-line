How the determinant reaches an integral matrix group

The interpolation step prescribes a determinant on every block. To use it in group homology, we must construct a map that realizes those numbers and find an integral matrix group carrying the resulting cycle. Start with the number field F in the cyclotomic layer over L′. For current divisors ai, aj, write C = I(d) and D = I(ai+d−aj). The proof chooses u ∈ C nonzero and v ∈ D so that uC−1 + vD−1 = 𝒪F. Express 1 in that sum as us − vr with s ∈ C−1, r ∈ D−1. The matrix with rows (u, v) and (r, s) has determinant one. The ideal memberships put the first output in I(ai+d) and the second in I(aj−d). The inverse has rows (s, −v) and (−r, u), giving the reverse inclusions. One pair of fractional ideals thus enforces all the valuation inequalities simultaneously. Apply this construction to the indices J = (ℤ/q)². At each unwanted slope the fiber sums of η vanish, so the specified determinants are all one. At the selected slope a coordinate with weight κh is conjugated by γ−h to have weight one, where γ(ζ) = ζκ. Equal powers of κ modulo q give equal powers of γ, so this choice is consistent. In the regrouped coordinates the divisors at 𝔓 sum to ord𝔓(β) on the weight-one block and zero on every other block. The weight-one block contains the coordinate (1,0). We have therefore realized β and the unit determinants by F-linear block maps. Undoing the conjugations produces an L′-linear map gt on FJ at each slope. On each regrouped block the cyclic action is scalar, so its block map commutes with that action. The prescribed determinants refer to those blocks.
