In the ordinary Hermitian form the two squared column lengths change from (2,1) to (2,3). Multiplying both inverses by 2 gives U = diag(1 − i, 2) and U′ = [[1 − i, −2], [0, 2]]. Each matrix specifies a compact set of forms. For a nonsingular representative B, impose qk(v) ≥ c on every nonzero integral vector and qk(Bⱼ) ≤ D on each column. These inequalities are closed in the real space of Hermitian tuples. The first gives a positive definite real Gram matrix for k/c. Testing it on real coordinates of a vector supported at a single place gives positivity there. The second bounds the entries of Bw∗kwBw in absolute value by 2D, using the sum of the two diagonal entries. Since Bw is invertible, these coordinates recover k by a continuous linear inverse on their image. The closed set is therefore compact. If B = g A, the transformed form satisfies qg·h(Bⱼ) = qh(Aⱼ).
