Four-character product, entire continuation, near-one upper bound, alternating Taylor series at s = 2, and the Estermann key inequality

Why does a Taylor expansion around s = 2 of a product of four L-functions force a quantitative lower bound on Re F(σ) for σ just below 1, supplying the engine behind Siegel’s lower bound and the exceptional-zero gap? For two real quadratic nonprincipal characters χ1 modulo q1 and χ2 modulo q2 whose induced product ψ modulo q1q2 is nonprincipal, the four-factor product F(s) = ζ(s) L(s, χ1) L(s, χ2) L(s, ψ) has nonnegative Dirichlet coefficients an ≥ 0 with a1 = 1, and only a single simple pole at s = 1, of residue λ = L(1, χ1) L(1, χ2) L(1, ψ). Subtracting λ/(s − 1) produces an entire function G(s). Because an ≥ 0, the derivatives of F at s = 2 alternate in sign with βn = ((−1)n/n!) F(n)(2) ≥ 0 and β0 = F(2) ≥ 1, while the derivatives of 1/(s − 1) at 2 are (−1)nn!. Expanding G(σ) about 2 in powers of x = 2 − σ ∈ (1, 9/8] therefore writes the first M Taylor terms as ∑n<M xnβn − λ(xM − 1)/(x − 1). When λ/(σ − 1) = −λ/(x − 1) is added back to recover F(σ), the pole term +λ/(x − 1) cancels identically, leaving a nonnegative sum at least 1, a negative residue penalty −|λ|(2 − σ)M/(1 − σ), and a Cauchy tail bounded via polynomial growth on the circle |s − 2| = 3/2 (from the zeta growth estimate and the partial-summation bound for nonprincipal characters). Choosing M of size log(q1q2)/log(4/3) cuts the tail below 1/2 and turns (2 − σ)M into a constant times (q1q2)K(1−σ).

1. Four-character product, near-one upper bound, and Estermann’s Taylor lower bound. Let q1, q2 ≥ 1 be positive integers and let χ1 modulo q1, χ2 modulo q2 be Dirichlet characters. Say that a character ψ modulo q1q2 is the product character of χ1 and χ2 if ψ(n) = χ1(n)χ2(n) for every natural number n. Define for complex s

F(s) = ζ(s) L(s, χ1) L(s, χ2) L(s, ψ),   λ = L(1, χ1) L(1, χ2) L(1, ψ),   G(s) = F(s) − λ/(s − 1),

with G(1) defined by removable continuation whenever χ1, χ2, ψ are nonprincipal. Write CG for a constant such that |L(s, χ)| ≤ CG q(1 + |s|) for every nonprincipal χ modulo q ≥ 1 and Re s ≥ 1/2 (from the local Dirichlet expansion), and set Cg = 14(9|CG|/2)3, CL = 38 e3/2, c0 = |Cg| + 54|CL|3 + 1, ℓ = log(4/3), K = 3/ℓ, and CB = e2 exp(log(8c0)/(8ℓ)).

|L(w, χ)| ≤ 38 e3/2 log(3q),   and in particular   |L(1, χ)| ≤ 38 e3/2 log(3q).

Since 1 < 2, every term of F(2) = ∑n≥1 an n−2 is nonnegative and the n = 1 term equals 1, so F(2) ≥ 1. Differentiating termwise at s = 2 gives (−1)nF(n)(2) = ∑k≥1 ak (log k)n k−2 ≥ 0, so βn = ((−1)n/n!) F(n)(2) ≥ 0 for every n ≥ 0, with β0 = F(2) ≥ 1. On the other hand, differentiating (s − 1)−1 n times at s = 2 yields (−1)nn!, so G(n)(2) = F(n)(2) − λ(−1)nn!. Now fix σ ∈ [7/8, 1), set x = 2 − σ ∈ (1, 9/8], and let M ≥ 1 be an integer. Because G is entire, its Taylor series at 2 converges at σ: G(σ) = ∑n=0M−1 tn + ∑k=0∞ tk+M, where tn = (n!)−1(σ − 2)nG(n)(2) = xnβn − λxn. Every term xnβn is real and nonnegative, so the finite sum has real part at least β0 ≥ 1. By Cauchy’s estimate on |s − 2| = 3/2, |G(m)(2)| ≤ m! Taking real parts with x − 1 = 1 − σ yields

1 − |λ| (2 − σ)M / (1 − σ) − 4B(3/4)M ≤ Re F(σ).

For Dirichlet series nonnegativity in (i), put f = (1 ∗ χ1) ∗ (χ2 ∗ ψ), a multiplicative arithmetic function with f(1) = 1 whose Dirichlet series for Re s > 1 equals (ζ(s)L(s, χ1))(L(s, χ2)L(s, ψ)) = F(s). Because f is multiplicative, it suffices to show f(pk) ≥ 0 for every prime p and k ≥ 0. Since χ12 = 1, the values of χ1(p) lie in {0, 1, −1}, so (1 ∗ χ1)(pj) = ∑i=0j χ1(p)i is always nonnegative (equal to 1, j + 1, or (1 + (−1)j)/2). Using ψ(n) = χ1(n)χ2(n) and complete multiplicativity of χ2, we have (χ2 ∗ ψ)(n) = χ2(n)(1 ∗ χ1)(n). If χ2(p) ∈ {0, 1}, then (χ2 ∗ ψ)(pj) ≥ 0 for all j, so the divisor convolution f(pk) is a sum of products of nonnegative terms. If χ2(p) = −1 and χ1(p) ∈ {0, 1}, swapping the symmetric roles of χ1 and χ2 reduces to the preceding case. In the last case χ1(p) = χ2(p) = −1, (1 ∗ χ1)(pj) vanishes for odd j and equals 1 for even j, so (−1)j(1 ∗ χ1)(pj) = (1 ∗ χ1)(pj) ≥ 0 for every j. For example, at p2 with χ1(p) = χ2(p) = −1, both factors take values (1, 0, 1) at (1, p, p2), giving f(p2) = 1·1 + 0·0 + 1·1 = 2 ≥ 0.

For entire continuation in (i), let ζ0(s) = ζ(s) − 1/(s − 1) for s ≠ 1 and ζ0(1) = γ; because ζ(s) − 1/(s − 1) → γ as s → 1, ζ0 is entire. Writing P(s) = L(s, χ1)L(s, χ2)L(s, ψ), which is entire since χ1, χ2, ψ are nonprincipal and satisfies P(1) = λ, the divided difference Q(s) = (P(s) − P(1))/(s − 1) (with Q(1) = P′(1)) is entire, and G(s) = ζ0(s)P(s) + Q(s) is entire with G(s) + λ/(s − 1) = (ζ(s) − 1/(s − 1))P(s) + (P(s) − λ)/(s − 1) + λ/(s − 1) = F(s) for all s ≠ 1.

For circle growth in (i), any s with |s − 2| = 3/2 satisfies Re s ≥ 2 − 3/2 = 1/2, |s| ≤ 2 + 3/2 = 7/2, and |s − 1| ≥ |s − 2| − 1 = 1/2. The zeta growth bound of the zeta zero-free region gives |ζ(s)| ≤ 1 + 1/|s − 1| + |s|(1 + 1/Re s) ≤ 1 + 2 + (7/2)·3 = 27/2 ≤ 14. The polynomial growth bound for each nonprincipal L-function gives |L(s, χ)| ≤ |CG| q(1 + 7/2) = (9/2)|CG| q; bounding q1, q2 ≤ q1q2 and multiplying all four factors gives |F(s)| ≤ 14(9|CG|/2)3(q1q2)3.

For the near-one bound (ii), a nonprincipal character modulo q cannot exist for q = 1 or q = 2 (whose unit groups are trivial), so q ≥ 3 and log(3q) ≥ log 9 > 2 (as e < 2.72 gives e2 < 9). Whenever 1 ≤ x ≤ 3q and t ≤ 3/(2 log(3q)), we have xt = exp(t log x) ≤ e3/2. Writing Aχ(M) = ∑n=1M χ(n), complete periodicity over a full period of length q gives |∑n=0M χ(n)| ≤ q, hence |Aχ(M)| ≤ q + 1 for every M. Because 1 ≤ q + 1 ≤ 3q, we have (q + 1)(q + 1)−Re w = (q + 1)1−Re w ≤ e3/2, bounding the boundary term by e3/2. With |w| ≤ 2 and Re w ≥ 1/4 we have |w|/Re w ≤ 8, so the tail bound (q + 1)(|w|/Re w)(q + 1)−Re w is at most 8 e3/2. Summing all three parts gives |L(w, χ)| ≤ e3/2(10 + log(3q)) ≤ 38 e3/2 log(3q) since log(3q) ≥ 2. Character existence, real-line sign control, same-character Euler-factor comparison, and Estermann–Landau deduction of Siegel’s lower bound

Why does the Estermann–Landau proof of Siegel’s theorem produce a lower bound |L(1, χ)| ≥ c(ε) q−ε for every ε > 0 while refusing to compute c(ε) explicitly, and how do both branches of the alternative collapse into a single inequality? Given ε > 0 and the exponent K ≥ 0 from the Estermann key inequality, fix the threshold σ0 = max(7/8, 1 − ε/(2(K + 1))) < 1, so that K(1 − σ) ≤ ε/2 throughout [σ0, 1). Either some real nonprincipal character χ1 modulo q1 has a real zero β ∈ [σ0, 1), or none does. In Case 1, fix such a pair (χ1, β) depending only on ε; then for every real nonprincipal χ modulo q and induced product ψ modulo q1q, the four-factor product F(β) vanishes identically because L(β, χ1) = 0, so Re F(β) ≤ 0. In Case 2, no real nonprincipal character vanishes on [σ0, 1); fix any concrete real nonprincipal character χ1 (namely the quadratic character χ4 modulo 4) and evaluate at σ = σ0 itself. Since L(·, ·) tends to 1 at +∞ and is real on the real axis, having no zeros on [σ0, ∞) forces L(σ0, χ1), L(σ0, χ), and L(σ0, ψ) (when ψ ≠ 1) all to be strictly positive, whereas ζ(σ0) < 0 on (0, 1); hence Re F(σ0) < 0 ≤ 0 directly, with no limit σ → 1− needed. Thus both cases supply a fixed pair (χ1, σ) with Re F(σ) ≤ 0 whenever ψ ≠ 1. Plugging Re F(σ) ≤ 0 into the Estermann key inequality yields 1/2 ≤ CB |L(1, χ1)| |L(1, χ)| |L(1, ψ)| (q1q)K(1−σ)/(1 − σ), bounding |L(1, χ)| from below by c q−ε; and in the degenerate case ψ = 1, χ1 and χ agree on all integers coprime to q1q, so comparing their Euler factors at s = 1 bounds |L(1, χ)| directly from |L(1, χ1)| > 0.

Cauchy first-derivative bound near s = 1 and deduction of the exceptional-zero gap

How does Siegel’s lower bound |L(1, χ)| ≥ c0 q−ε/3 exclude real zeros β of L(s, χ) within distance c q−ε of 1, supplying the gap 1 − β ≥ c q−ε invoked in the exceptional denominator test, the small-modulus relative error, power-sum repulsion, and the relative progression count? If β is a real zero very close to 1, say β > 1 − 1/log(3q), then L(1, χ) = L(1, χ) − L(β, χ) is bounded in absolute value by (1 − β) times the maximum of |L′(σ, χ)| over [β, 1]. Because the near-one estimate holds throughout Re w ≥ 1 − 3/(2 log(3q)) (including Re w > 1 on the right half of a circle centred at σ ≤ 1), placing a Cauchy circle of radius 1/(2 log(3q)) around any real σ ∈ [1 − 1/log(3q), 1] divides the bound 38 e3/2 log(3q) by 1/(2 log(3q)) to give |L′(σ, χ)| ≤ 76 e3/2 (log(3q))2 (the same circle derivative bound also enters the positive prime moment). Absorbing each factor of log(3q) into qε/3 turns |L(1, χ)| ≥ c0 q−ε/3 into 1 − β ≥ c q−ε.

Because χ ≠ 1 we have q ≥ 3 and log(3q) ≥ 2, so 1/log(3q) ≤ 1/2 and the Cauchy radius ρ = 1/(2 log(3q)) satisfies 0 < ρ ≤ 1/4. Take any complex z on the circle |z − σ| = ρ. Then |Re z − σ| ≤ ρ, so Re z ≥ σ − ρ ≥ 1 − 1/log(3q) − 1/(2 log(3q)) = 1 − 3/(2 log(3q)), and also Re z ≥ 1 − 1/2 − 1/4 = 1/4; moreover, σ ≥ 1 − 1/2 > 0 and σ ≤ 1 give |z| ≤ |z − σ| + |σ| ≤ 1/4 + 1 < 2. Thus the near-one bound applies to every point on the circle |z − σ| = ρ, giving |L(z, χ)| ≤ 38 e3/2 log(3q). Because L(·, χ) is entire, Cauchy’s derivative estimate on that circle yields

|L′(σ, χ)| ≤ (38 e3/2 log(3q)) / (1/(2 log(3q))) = 76 e3/2 (log(3q))2.

For (ii), fix ε > 0, let q ≥ 1 and χ modulo q be real and nonprincipal, and suppose L(β, χ) = 0 for a real β. Since a nonprincipal L-function has no zeros in Re s ≥ 1, we have β < 1. Set u = qε/3 ≥ 1, so that q−ε/3 = u−1 and q−ε = (u3)−1. From log(3q) = log 3 + log q ≤ (log 3)u + u/(ε/3) = Kε u, consider two cases:

If β ≤ 1 − 1/log(3q), then c ≤ 1/Kε and u ≤ u3 give c log(3q) ≤ (1/Kε)(Kε u) = u ≤ u3, so c q−ε = c / u3 ≤ 1/log(3q) ≤ 1 − β.

If instead β > 1 − 1/log(3q), then every t ∈ [β, 1] lies in [1 − 1/log(3q), 1], where (i) bounds |L′(t, χ)| by CD (log(3q))2 ≤ MD (Kε u)2. Applying the mean-value inequality to the smooth map t ↦ L(t, χ) on [β, 1] with L(β, χ) = 0, and combining with Siegel’s lower bound |L(1, χ)| ≥ c0 u−1, gives

c0 u−1 ≤ |L(1, χ) − L(β, χ)| ≤ MD (Kε u)2 (1 − β).

Multiplying by u yields c0 ≤ MD Kε2 u3 (1 − β), whence c q−ε = c / u3 ≤ (c0/(MD Kε2)) / u3 ≤ 1 − β. In both cases β ≤ 1 − c q−ε.

Logarithmic absorption log(3q) ≤ (log 3 + 3/ε) qε/3 and the power-splitting identity

For any δ > 0 and real x ≥ 1, the elementary inequality log x ≤ xδ/δ (from y ≤ ey applied to y = δ log x) and 1 ≤ xδ give log(3x) = log 3 + log x ≤ (log 3)xδ + xδ/δ = (log 3 + 1/δ)xδ. Taking δ = ε/3 gives log(3q) ≤ Kε qε/3 for every q ≥ 1. Moreover, for any x > 0 and integer k ≥ 1, (xε/k)k = xε, so x−ε = ((xε/k)k)−1; taking k = 3 splits the exponent ε evenly into one factor q−ε/3 for Siegel’s lower bound on |L(1, χ)| and two factors qε/3 for (log(3q))2 in the derivative estimate. For any nonprincipal character χ modulo q, both q = 1 and q = 2 have a single unit modulo q (the class 1), so every character modulo 1 or 2 is principal; hence q ≥ 3 and log(3q) ≥ log 9 > 2 automatically.
