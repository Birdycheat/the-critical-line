Möbius action on the Hilbert upper half-plane and balanced height floors

Controlling the one-vector discrepancy in the unbounded cusp argument begins by moving an arbitrary tuple τ = (τw)w in the product upper half-plane ℍ[F ∶ ℚ] (for a totally real number field F) into a fixed Siegel region where every height yw = Im τw is bounded below and comparable to every other height. Geometrically, the modular group SL2(F) acts diagonally through the [F ∶ ℚ] real embeddings ρw ∶ F → ℝ; each coordinate moves by a real fractional-linear transformation, while multiplying by a diagonal unit rescales the coordinates by squares of real embeddings without altering their product. Once cusp-row completion (see the cusp row construction) yields a product lower bound on the heights and unit balancing (see the height inequalities) forces all pairwise ratios into a compact interval, every individual height automatically clears a uniform positive floor.

Proposition (Hilbert-plane Möbius action, norm-square product, and balanced height floor). Let F be a number field with real embeddings ρw ∶ F → ℝ indexed by the infinite places w of F, and let τ = (τw)w satisfy Im τw > 0 for every w. For any matrix γ = (a, b; c, d) in SL2(F), define (γ · τ)w = (ρw(a) τw + ρw(b)) / (ρw(c) τw + ρw(d)).

  1. Well-defined left action and height formula. For every γ ∈ SL2(F) and every infinite place w, the denominator ρw(c) τw + ρw(d) is nonzero, Im((γ · τ)w) > 0, and
    Im((γ · τ)w) = Im(τw) / |ρw(c) τw + ρw(d)|2.
    The map (γ, τ) ↦ γ · τ satisfies (γ γ′) · τ = γ · (γ′ · τ) for all γ, γ′ ∈ SL2(F). On the unipotent, diagonal, and Weyl generators n(b) = (1, b; 0, 1) (b ∈ F), m(a) = diag(a, a−1) (a ∈ F×), and w0 = (0, 1; −1, 0), it acts coordinatewise by (n(b) · τ)w = τw + ρw(b), (m(a) · τ)w = ρw(a)2 τw, and (w0 · τ)w = −τw−1.
  2. Totally real norm-square product. If F is totally real and each ρw agrees with the canonical real embedding attached to w, then ∏w ρw(x)2 = NF/ℚ(x)2 for every x ∈ F.
  3. Balanced lower bound. Let I be a finite nonempty index set, let zi > 0 for every i ∈ I, and let κ > 0 and P ∈ ℝ satisfy κ zw ≤ zv for all v, w ∈ I together with P ≤ ∏i ∈ I zi. Then every coordinate satisfies
    zw ≥ κ min(1, P)   for every w ∈ I.

Proof. Fix a real matrix with entries a, b, c, d ∈ ℝ satisfying a d − b c = 1 and a complex number τ with Im τ > 0. If c τ + d = 0, taking imaginary parts gives c Im τ = 0, hence c = 0, and taking real parts then gives d = 0, contradicting a d − b c = 1. Multiplying numerator and denominator of (a τ + b)/(c τ + d) by the conjugate of c τ + d yields imaginary part ((a d − b c) Im τ) / |c τ + d|2 = Im τ / |c τ + d|2 > 0. Applying each ring homomorphism ρw to det γ = 1 yields ρw(a) ρw(d) − ρw(b) ρw(c) = 1, establishing the height formula and positivity at every place w. Associativity follows coordinatewise by clearing the nonzero denominator c′ τ + d′ in both numerator and denominator of the iterated fraction, and direct substitution evaluates the action of n(b), m(a), and w0.

When F is totally real, every infinite place w has multiplicity one and satisfies |x|w = |ρw(x)|, so the product formula ∏w |x|w = |NF/ℚ(x)| squares directly to ∏w ρw(x)2 = NF/ℚ(x)2. For the balanced lower bound, suppose to the contrary that zw < κ min(1, P) for some w ∈ I, and set q = zw / κ. Then 0 < q < min(1, P), so q ≤ 1 and q < P. By the balance inequality κ zv ≤ zw, every index v ∈ I satisfies zv ≤ q. Multiplying over the nonempty finite set I (so |I| ≥ 1) gives P ≤ ∏i ∈ I zi ≤ q|I| ≤ q < P, a contradiction. ∎

Coordinate composition algebra and a real quadratic balancing check

Clearing denominators in the composition law. For two real matrices (a, b; c, d) and (a′, b′; c′, d′) of determinant one and τ ∈ ℍ, let τ′ = (a′ τ + b′)/(c′ τ + d′). Because c′ τ + d′ ≠ 0 and Im τ′ > 0, we also have c τ′ + d ≠ 0. Writing a τ′ + b = ((a a′ + b c′) τ + (a b′ + b d′))/(c′ τ + d′) and c τ′ + d = ((c a′ + d c′) τ + (c b′ + d d′))/(c′ τ + d′), cancellation of the common nonzero factor c′ τ + d′ gives the exact entrywise matrix-product action. For m(a) = diag(a, a−1), since ρw(a) ≠ 0 and ρw(a−1) = ρw(a)−1, the fraction (ρw(a) τw + 0)/(0 · τw + ρw(a)−1) simplifies to ρw(a)2 τw.

Worked check (real quadratic balancing). Take F = ℚ(√5) with real embeddings ρ1(a + b√5) = a + b√5 and ρ2(a + b√5) = a − b√5, and fundamental unit ε = (1 + √5)/2. Then ρ1(ε)2 = (3 + √5)/2 and ρ2(ε)2 = (3 − √5)/2, whose product is (9 − 5)/4 = 1 = NF/ℚ(ε)2. Starting from the unbalanced point τ = (i/4, 4i) of height product P = 1, applying m(ε) produces new imaginary parts z1 = (3 + √5)/8 ≈ 0.6545 and z2 = 6 − 2√5 ≈ 1.5279, preserving z1 z2 = 1 while tightening the ratio to z1/z2 = (7 + 3√5)/32 ≈ 0.4284. Taking κ = 1/3 gives κ zw ≤ zv for both places, and the balanced lower bound immediately certifies zw ≥ (1/3) min(1, 1) = 1/3 at every place. Likewise, applying w0 to 1 + i/2 gives −1/(1 + i/2) = −4/5 + (2/5)i, matching (1/2)/|1 + i/2|2 = (1/2)/(5/4) = 2/5.

In the cusp discrepancy argument, reducing τ to a Siegel domain by an integral matrix k ∈ SL2(𝒪F) transforms the finite Schwartz–Bruhat test φ by the adelic Weil representation, while the Eisenstein tail requires an inverse-denominator power bound den(b)−M on every finite-adelic orbital integral f*(φ, b) = ∫𝔸F,f2M ψ(b · ½ u⊤ B u) φ(u) dμf(u). Split-extension parabolic Haar measure, modular triviality, and quotient unfolding

When the isotropic-vector shell count in the one-vector discrepancy bound splits off a hyperbolic plane, the stabilizer of a rational isotropic line is a parabolic subgroup P = N ⋊ G1 whose normal kernel N is unipotent (with cocompact discrete lattice Γ ∩ N) and whose Levi factor G1 carries a finite-covolume arithmetic lattice Γ1. To integrate nonnegative measurable functions over a fundamental domain of Γ in P by unfolding into an inner integral over the kernel quotient (Γ ∩ N) ∖ N and an outer integral over the Levi quotient Γ1 ∖ G1, two measure-theoretic facts must hold: the product measure ν ⊗ μ1 must push forward to a genuine left Haar measure on P (requiring conjugation by G1 to preserve ν unimodularly), and the product of fundamental domains D × 𝓕1 must form a genuine finite-covolume fundamental domain for Γ in P. Remarkably, conjugation unimodularity is forced automatically by finite covolume of Γ1 via a logarithmic-shell pigeonhole contradiction, with no Lie-algebra determinant calculation required.

  • μ1 is a left Haar measure on G1 possessing a fundamental domain 𝓕1 for Γ1 of finite measure μ1(𝓕1) < ∞;
  • there exists a compact subset K ⊂ P such that every m ∈ N admits γ ∈ Γ ∩ N with γ m ∈ K.

∫𝓕P f(p) dμP(p) = ∫𝓕1 ∫D f(m · ι(u)) dν(m) dμ1(u).

Covering and disjointness verification and a semidirect lattice example

Covering and disjointness step by step. For almost-everywhere covering, since 𝓕1 covers G1 modulo a μ1-null set, the projection (m, u) ↦ u ensures that for (ν ⊗ μ1)-almost every (m, u) there exists γ1 ∈ Γ1 with γ1 u ∈ 𝓕1. Choosing the unique δ0 ∈ ΓN moving (ι(γ1) · ι(π(ι(γ1)))−1) · cγ1(m) = cγ1(m) into D, the product γ = δ0 · ι(γ1) lies in Γ and satisfies γ · (m · ι(u)) = (δ0 · cγ1(m)) · ι(γ1 u) ∈ Φ(D × 𝓕1). For disjointness, fix γ ∈ Γ ∖ {1}. If x ∈ (γ · 𝓕P) ∩ 𝓕P with x = γ · Φ(m, u) = Φ(m′, u′), applying π yields π(γ) u = u′ ∈ (π(γ) · 𝓕1) ∩ 𝓕1. If π(γ) ≠ 1, then (γ · 𝓕P) ∩ 𝓕P lies inside π−1((π(γ) · 𝓕1) ∩ 𝓕1) = Φ(N × ((π(γ) · 𝓕1) ∩ 𝓕1)), whose μP-measure is ν(N) · 0 = 0. If π(γ) = 1, then γ ∈ ΓN ∖ {1}, u′ = u, and cancelling ι(u) gives m′ = γ m with both m, m′ ∈ D, contradicting uniqueness in D and showing the intersection is literally empty.

Worked check on the affine-modular semidirect product. Consider P = ℝ2 ⋊ SL2(ℝ) with N = ℝ2, G1 = SL2(ℝ), Γ = ℤ2 ⋊ SL2(ℤ), and Γ1 = SL2(ℤ). Here ΓN = ℤ2 is cocompact in ℝ2 with strict measurable fundamental domain D = [0, 1)2 of Lebesgue measure ν(D) = 1, while SL2(ℤ) has finite covolume μ1(𝓕1) < ∞ in SL2(ℝ). Conjugation by u ∈ SL2(ℝ) acts on ℝ2 by linear multiplication by u, whose Jacobian |det u| = 1 agrees with the automatic conclusion δ ≡ 1; consequently 𝓕P = [0, 1)2 × 𝓕1 has covolume 1 · μ1(𝓕1) and unfolds any nonnegative measurable integral directly. By contrast, replacing G1 by the multiplicative group ℝ>0 acting on N = ℝ by scaling cu(x) = u x produces the nontrivial modular character δ(u) = u−1 (since ν(cu−1([0, 1])) = ν([0, u−1]) = u−1), which can occur only because ℝ>0 admits no finite-covolume lattice on which δ is trivial.
