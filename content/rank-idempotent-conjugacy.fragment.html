How can one change all the weight projectors at once?

Let A be the algebra generated by the tangent matrices. Its weight projectors pi are nonzero, are pairwise orthogonal and sum to the identity. Let q1, …, qm be a second family in A with the same three properties. Suppose that each diagonal corner for either family is scalar. In the application qi = D−1piD, where D = ρ(g). These corners are scalar because conjugation by D preserves A. We seek a change of basis inside A itself. Scalar corners of products.

Proposition. There are an invertible v in A and a permutation π of the indices such that v pi = qπ(i)v for every i. The permutation can fix every i for which qiA pi contains a nonzero map.

We first describe the coordinates in which to compare the two families. The nilpotence test for A gives, for each nonzero x in A, some b in A for which bx is not nilpotent. Applied with scalar corners, the matrix-unit construction groups the indices into classes C according to whether piA pj is nonzero. Within each class this space has basis Eij, with Eii = pi and EijEjk = Eik. Products with unequal middle indices vanish. Sending these elements to the ordinary matrix units gives

A ≃ ∏C EndK(UC),   UC = KC.

Indeed, each a in A is the sum of its blocks, and any choice of coefficients of the Eij gives such an element. In this model pi projects onto a coordinate line of UC. Its image on the original space of ρ may have higher dimension.

Consider a single projector q from the second family. Write qC for its component on UC. The corner qAq acts there by all endomorphisms of the image of qC, independently in each class. Indeed, an endomorphism of this image extends by zero on the kernel of qC. Thus the dimension of qAq is the sum of the squares of the ranks of the qC. Since qAq = Kq has dimension one, exactly one component has rank one and all others vanish.

For a given class C, let JC be the labels of the qj supported there. Their image lines form a direct sum equal to UC, by orthogonality and completeness. Consequently |JC| = |C|. For i in C, a map in qjA pi can be nonzero precisely when j lies in JC. Within a single full matrix algebra we can send the coordinate vector of i to any nonzero vector on the image line of qj. Maps between distinct factors vanish.

Match the labels of C to those of JC by first fixing their intersection, then pairing the equally many remaining labels in any order. Combining the matchings gives π. In each UC, send the ith coordinate vector to a nonzero vector on the line of qπ(i). These images form a basis, so the maps define a unit v in the product algebra. Checking on this basis gives v pi = qπ(i)v. The fixed labels are exactly the intersections chosen above.

Which part of the change of basis moves the weight spaces?

Proposition. Every unit v of A has a factorization

v = ud,   d = ∑i dipi,   di ∈ K×,

where u is a product of transvections I + N. Here each N belongs to a single off-diagonal block piA pj. It squares to zero, so the inverse transvection is I − N.

In a class C the matrix of v is invertible. Reduce it to a diagonal matrix using row additions. If the next pivot entry vanishes, the remaining square submatrix is invertible, so a lower row has a nonzero entry in that column. Adding this row to the pivot row supplies a pivot and preserves the zeros in the earlier columns. Clear the entries below each pivot in turn, then use the pivots in reverse order to clear the entries above them. All diagonal entries are nonzero. MIT 18.700, Gaussian elimination, Theorem 4.8.

Adding c times row j to row i is left multiplication by I + cEij in the model. This element is the identity on the other classes. Apply the row additions in each class to get Ts⋯T1v = d. Inverting the transvections gives u = T1−1⋯Ts−1. Since d commutes with all pi, the relation for v gives u pi = qπ(i)u. For qj = D−1pjD, this says that Du carries the image of pi onto the image of pπ(i).
