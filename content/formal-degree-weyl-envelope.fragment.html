Compact Weyl dimension formula on U(p) × U(q) and shifted Vandermonde limit

Why does multiplying dim(Tt)/d(λ(t)) by tpq along the admissible ray λa(t) = λa + t(N − 1 − a) isolate a finite positive limit proportional to V(λ)/d(λ)? Because the shifted-model embedding keeps the ratio d(λ(t))/V(λ(t)) constant along integer steps, the denominator d(λ(t)) grows like the full Vandermonde product V(λ(t)) over all N(N − 1)/2 ordered index pairs 0 ≤ a < b < N. By contrast, the compact Weyl dimension formula for the lowest K-type Tt of K ≃ U(p) × U(q) multiplies linear factors only across the p(p − 1)/2 + q(q − 1)/2 same-sign pairs (εa = εb), leaving the pq opposite-sign pairs (εa ≠ εb) unmatched in the denominator. On every same-sign pair, shifting the compact highest weight Λ(t) = λ(t) + ρn − ρc by the compact half-sum ρc adds the noncompact half-sum difference ρn,a − ρn,b, which equals the fixed count na,b of opposite-sign indices strictly between a and b; dividing by λa(t) − λb(t) produces a factor tending to 1. Meanwhile, each of the pq opposite-sign differences λb(t) − λa(t) (0 ≤ b < a < N, εa ≠ εb) grows like t(a − b), so pairing it with one power of t from tpq yields 1/(a − b) in the limit and assembles the opposite-sign index product A.

1. Compact unitary Weyl product and intermediate opposite-sign count. Fix integers p ≥ 1 and q ≥ 1, put N = p + q, and let ε : {0, …, N − 1} → {+, −} assign p positive signs and q negative signs to the ordered indices. Write Fm = ∏0≤a<m a! = ∏0≤a<b<m (b − a) for the superfactorial product and A = ∏0≤b<a<N, εa≠εb (a − b) > 0 for the product over the pq opposite-sign pairs (matching ∏(j − i) over opposite-sign pairs 0 ≤ i < j < N in the constant comparison). Define the compact and noncompact half-sums on {0, …, N − 1} by ρc,a = (1/2)(#{c > a : εc = εa} − #{c < a : εc = εa}) and ρn,a = (1/2)(#{c > a : εc ≠ εa} − #{c < a : εc ≠ εa}). Let λ = (λ0, …, λN−1) ∈ ℝN be a strictly decreasing Harish-Chandra parameter (λ0 > λ1 > ⋯ > λN−1) with λa − (N − 1)/2 ∈ ℤ for every 0 ≤ a < N, so that V(λ) = ∏0≤a<b<N (λa − λb) > 0 and Λ = λ + ρn − ρc ∈ ℤN is dominant (antitone) within each sign block.

Proposition (Compact Weyl dimension and shifted Vandermonde limit). Every irreducible unitary representation T of K ≃ U(p) × U(q) of highest weight Λ (integral and antitone on each sign block) has dimension dim(T) = [∏0≤a<b<N, εa=εb ((Λ + ρc)a − (Λ + ρc)b)] / (FpFq). For every same-sign pair 0 ≤ a < b < N (εa = εb), one has ρn,a − ρn,b = na,b := #{c : a < c < b, εc ≠ εa}, so the lowest compact type T of highest weight Λ = λ + ρn − ρc satisfies

dim(T) = [∏0≤a<b<N, εa=εb (λa − λb + na,b)] / (FpFq).

Furthermore, along the integer ray λa(t) = λa + t(N − 1 − a) (t ∈ ℕ) with lowest compact types Tt of highest weight Λ(t) = λ(t) + ρn − ρc and positive formal degrees satisfying d(λ(t))/V(λ(t)) = d(λ)/V(λ) (d(λ) > 0), the sequence Yt = tpq dim(Tt)/d(λ(t)) obeys

Yt = [V(λ) / (d(λ)FpFq)] · [∏0≤a<b<N, εa=εb (λa(t) − λb(t) + na,b)/(λa(t) − λb(t))] · [∏0≤b<a<N, εa≠εb t/(λb(t) − λa(t))],   limt→∞ Yt = V(λ) / [d(λ)FpFqA].

In particular, if limt→∞ Yt = cπpq/A with c = FN/(πpqFpFq), then d(λ) = V(λ)/FN.

Proof. For an antitone integer tuple ν0 ≥ ⋯ ≥ νm−1, the irreducible polynomial (or determinant-twisted) dual-Weyl module of U(m) has dimension ∏0≤i<j<m (νi − νj + j − i)/(j − i) = [∏0≤i<j<m (νi − νj + j − i)] / Fm. Under the strictly increasing enumerations e+ : {0, …, p − 1} → {0, …, N − 1} and e− : {0, …, q − 1} → {0, …, N − 1} of the positive- and negative-sign indices, every same-sign pair 0 ≤ a < b < N is uniquely (e+(i), e+(j)) or (e−(i), e−(j)) with i < j, and counting same-sign elements above and below e±(i) gives (ρc)e±(i) − (ρc)e±(j) = j − i. Multiplying the U(p) and U(q) dimensions therefore produces the compact Weyl product over εa = εb with denominator FpFq. When 0 ≤ a < b < N satisfy εa = εb, any opposite-sign index c with c < a or c > b lies on the same side of a and b and cancels in ρn,a − ρn,b, whereas each c with a < c < b contributes +1/2 − (−1/2) = 1, giving ρn,a − ρn,b = na,b and hence (Λ + ρc)a − (Λ + ρc)b = λa − λb + na,b.

Along λa(t) = λa + t(N − 1 − a), substitute d(λ(t)) = [d(λ)/V(λ)]V(λ(t)), factor V(λ(t)) into same-sign differences λa(t) − λb(t) (0 ≤ a < b < N, εa = εb) times opposite-sign differences λb(t) − λa(t) (0 ≤ b < a < N, εa ≠ εb), and distribute tpq across the pq opposite-sign pairs to obtain the factored expression for Yt. For 0 ≤ a < b < N with εa = εb, λa(t) − λb(t) = (λa − λb) + t(b − a) → ∞ as t → ∞ while na,b is independent of t, so (λa(t) − λb(t) + na,b)/(λa(t) − λb(t)) → 1. For 0 ≤ b < a < N with εa ≠ εb, λb(t) − λa(t) = (λb − λa) + t(a − b) with a − b ≥ 1, so t/(λb(t) − λa(t)) = 1/[a − b + (λb − λa)/t] → 1/(a − b). Multiplying these finite-product limits yields limt→∞ Yt = V(λ)/[d(λ)FpFqA]. Finally, cπpq/A = FN/(FpFqA); since Fp, Fq, A, FN, V(λ), and d(λ) are all strictly positive, cancelling 1/(FpFqA) gives the formal-degree identity d(λ) = V(λ)/FN.

Gelfand–Tsetlin interlacing count, sign-block half-sum shifts, and superfactorial denominator

For ν0 ≥ ν1 ≥ ⋯ ≥ νm−1 ≥ 0 in ℤm, branching the polynomial dual-Weyl representation of U(m) along U(m) ⊃ U(m − 1) ⊃ ⋯ ⊃ U(1) indexes a basis by triangular Gelfand–Tsetlin patterns whose consecutive rows interlace; induction on m via discrete polynomial summation over the (m − 1)-row weights evaluates the cardinality as ∏0≤i<j<m (νi − νj + j − i)/(j − i). Twisting by dets (s ∈ ℤ) shifts every νi equally and leaves all differences νi − νj unchanged, while highest-weight classification identifies every irreducible unitary representation of U(m) of highest weight ν with this model. Grouping the denominator by its larger index b gives ∏0≤a<b<m (b − a) = ∏b=0m−1 ∏a=0b−1 (b − a) = ∏b=0m−1 b! = Fm (and at m = N identifies the Weyl denominator FN in V(λ)/FN).

Under e+ : {0, …, p − 1} → {a : εa = +}, order preservation implies #{c < e+(i) : εc = +} = i and #{c > e+(i) : εc = +} = p − 1 − i, whence (ρc)e+(i) = (p − 1)/2 − i and (ρc)e+(i) − (ρc)e+(j) = j − i (and identically (ρc)e−(i) = (q − 1)/2 − i). Since (ρc + ρn)a = (1/2)(#{c > a} − #{c < a}) = (N − 1)/2 − a, the congruence λa − (N − 1)/2 ∈ ℤ forces Λa = λa + (N − 1)/2 − a − 2ρc,a ∈ ℤ, and for a = e±(i) < e±(i + 1) = b strict decrease λa − λb > 0 with λa − λb ∈ ℤ implies λa − λb ≥ 1, so Λa − Λb = λa − λb + na,b − 1 ≥ 0. Finally, for 0 ≤ a < b < N with εa = εb, partitioning {c : εc ≠ εa} into c < a, a < c < b, and b < c writes 2(ρn,a − ρn,b) = ∑c<a, εc≠εa (−1 − (−1)) + ∑a<c<b, εc≠εa (1 − (−1)) + ∑b<c, εc≠εa (1 − 1) = 2na,b.
