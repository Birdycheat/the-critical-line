When is a space of block maps one-dimensional?

Let B be any unital matrix algebra containing the projectors. Suppose its diagonal corners are scalar and each nonzero x admits b ∈ B such that bx is not nilpotent. We will apply the result twice, first to the tangent-generated algebra A and later to the algebra containing all group matrices.

Consider the space piBpj of block maps from Vj to Vi, where Vi = piV. Any nonzero member x has an inverse between these two spaces. To see this, choose b ∈ B with bx nonnilpotent, using the assumed test. Then xbx ≠ 0, since otherwise (bx)² = 0. Put z = pjbpi. Both xz and zx lie in diagonal blocks, so each is a scalar times its projector. Their scalars coincide and are nonzero because (xz)x = x(zx) = xbx ≠ 0. Divide z by that scalar to obtain the inverse y. For any other map w in the same block, wy is scalar on Vi and w = (wy)x. Thus a nonzero block space is one-dimensional, even when its maps act on large eigenspaces.

Group indices into classes by declaring i and j related when their block space is nonzero. Identity maps, inverse maps and compositions give reflexivity, symmetry and transitivity. In each class C choose a base index b and isomorphisms ui from Vb to Vi in their block spaces, taking the identity at b. Within the class set Eij = uiuj−1. These are matrix units, with EijEjk = Eik. Write each block of a ∈ B as cij(a)Eij when the indices belong to one class. Take the coefficient to be zero between classes. Inserting the identity ∑ pj between a and b gives

cik(ab) = ∑j cij(a) cjk(b).

Every matrix unit belongs to B. Within each class its entries can therefore be chosen independently by taking linear combinations of these units. Entries between classes vanish. Conversely, all the coefficients together determine the original endomorphism by summing its blocks. Thus the coefficient map identifies B with the product, over the classes, of the corresponding full matrix algebras.
