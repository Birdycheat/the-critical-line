Choosing correction radii on a cycle

The correction attached to a coordinate has two parts to its construction. First assign one price σs to each row label s. Then adjust individual coordinates at the rows distinguished by the frame. The first problem has an exact optimum. For the adjustment, an explicit choice with a bounded total cost suffices.

Take integers p ≥ 3 and even d ≥ 2. The optimization itself imposes no primality condition on p. Labels belong to ℤ/dℤ. Give each label a real capacity Ds ≥ 0. For each odd integer 1 ≤ j < d, an amount xs,j ≥ 0 sent from s to s + j consumes pj units of capacity at its starting point and one unit at its endpoint per unit sent. Thus the load at s is ∑j (pjxs,j + xs−j,j). Require this load to be at most Ds. Write V for the largest total ∑s,j xs,j. The zero flow is feasible. After setting unused coordinates to zero, every used coordinate lies between 0 and ∑s Ds. The continuous objective therefore attains its maximum on a closed subset of a compact box. A feasible price vector has 0 ≤ σs ≤ 1 and pjσs + σs+j ≥ 1 on every edge. Multiply each edge inequality by the amount sent, sum, and translate the index in the incoming sum. This gives ∑s,j xs,j ≤ ∑s σs load(s) ≤ ∑s Dsσs. Equality of the optimal values yields the gain used in the coefficient estimate, with γ = p/(p²−1). The weighted load identity

F(D) = γ ∑s Ds − V = maxfeasible σ ∑s Ds(γ − σs).

To prove equality, let C consist of pairs (b,t) for which a nonnegative flow has load ≤ b in every row and value ≥ t. This is a convex cone. It is closed because for a converging sequence of pairs, their capacities stay bounded. Truncate the witnessing flows, take a convergent subsequence in a common box, and pass the load and value inequalities to the limit. For η > 0, the point (D,V + η) lies outside C. Strict separation gives a linear functional a·b + c t which is nonnegative on the cone and negative at that point. Independent positive capacity increments belong to the cone, so as ≥ 0. Since D ≥ 0 and V + η > 0, negativity forces c < 0. Test a unit flow on each edge. Its load and value give pjas + as+j + c ≥ 0. Dividing by −c supplies prices of cost < V + η. Clipping each price at 1 preserves every edge inequality. If either endpoint price was clipped, that endpoint alone now contributes at least 1 since pj ≥ 1. Clipping can only lower the cost because D ≥ 0. The feasible prices form a closed subset of the unit cube containing the all-ones vector, so the minimum exists. It is below V + η for every η > 0 and at least V by the load identity. Finally, every positive odd exponent j reduces modulo the even period d to another odd exponent r < d. The endpoint is unchanged and pjσs ≥ prσs. Thus the same optimizer satisfies the inequalities at all odd levels. From a row price to a coefficient bound

In the frame, a coordinate has label s, row index k < N0, and a further index below N1. At each distinguished label s in a set T, the coordinates with k = 0 form its top row. Their total derivative order is ν1(s). The remaining orders sum to Ds, which equals size(s) − ν1(s) on T and size(s) elsewhere. Assume 0 ≤ ν2 ≤ ν1 ≤ size. Define the row cap Cs as ν2(s) on T and ν1(s) elsewhere. A special non-top row carries an origin u ∈ T and a signed odd shift j with s = u + j. The total order assigned the same pair (u,j) is at most Cs. Positive shifts require pj ≤ ν1(u), and negative shifts require p|j| ≤ Ds. Row data and top distances · Exact assembly hypotheses
