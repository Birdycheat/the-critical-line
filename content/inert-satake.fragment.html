Why the two functions have the same sum on a double class

The coefficient w is constant on each double class D = KgK. The induced function φ is easier to evaluate on triangular matrices, and its values can vary within D. To compare them, use D itself as a test. Here G is the rank-n unitary group at the inert place, and K its integral subgroup. A Hecke function h is invariant under K on both sides and supported on finitely many double classes. Each double class contains finitely many cosets xK. With vol(K) = 1, right translation gives the following finite sum for a right-K-invariant function F.

(ThF)(g) = ∑xK ∈ G/K h(x)F(gx),   (T1DF)(1) = ∑xK ⊂ D F(x).

The second formula sets h equal to the indicator of D. Thus two functions with the same normalized Hecke values at the identity have the same sum on every double class. Build the induced function. Write B for the upper triangular subgroup, m = ⌊n/2⌋, and index the first m diagonal entries of b ∈ B from 0. Let aᵢ be their additive valuations, with v(ϖ) = 1. For nonzero complex parameters αᵢ and base residue size q, define

Aα(a) = ∏0 ≤ i < m αᵢaᵢ q−(n−1−2i)aᵢ,   φ(bk) = Aα(a)   (k ∈ K).

Iwasawa decomposition supplies g = bk. If bk = b′k′, then b′−1b lies in B ∩ K. Its diagonal entries and their inverses are integral, so all their valuations vanish. Diagonal entries multiply in a triangular product, so the weight is independent of the choice. In particular φ(1) = 1. Any function ψ with the same left B transformation law and right K invariance satisfies ψ(bk) = Aα(a)ψ(1). This makes the space of such functions one-dimensional. Compute the Hecke scalar. Every coset xK has a representative t(a)u, where u is upper triangular unipotent. The diagonal t(a) starts with the powers ϖaᵢ, ends with their inverses in reverse order, and has a central 1 in odd rank. To obtain it, remove the diagonal unit factors of b into K. Two such triangular representatives for the same coset differ by an element of B ∩ K, so they give the same exponents. Let a(xK) denote that vector. Then φ(x) = Aα(a(xK)). Grouping the finite terms of Thφ(1) by exponent vector gives the following value of the Satake transform.

Satα(h) = ∑a ∈ ℤm Aα(a) ∑a(xK) = a h(x).

The function Thφ still transforms on the left by the same triangular weight. For right invariance, multiplication by k permutes the cosets xK, and left invariance of h preserves their weights. The one-dimensionality above now gives Thφ = Satα(h)φ everywhere. A double class with twelve terms and three different weights

Work over ℚ₃(i), i² = −1, with its anti-diagonal unitary group in rank two. Take d = diag(3,1/3) and D = KdK. Write u(c) for the upper unitriangular matrix with upper entry c. Unitarity gives c + σ(c) = 0, so c ranges over iℚ₃. The triangular labels are dau(c)K. At fixed a, two labels agree exactly when their corners differ by an element of iℤ₃.
