How many lists of minors have a given size?

Fix a diagonal word u and an intersection defect j with 1 ≤ j ≤ r. Each surviving term supplies an ordered list δ = (δ₁, …, δj) of leading determinants. Two terms can supply exactly the same list. The fixed-list estimate has already paid for the terms with that list. We now count each distinct list once. Vanishing intermediate determinants retain their positions.

Both frames belong to the same self-dual Hermitian lattice. Pairing a vector in its dual with a lattice vector gives an element of the ring of integers 𝒪E. Every matrix entry therefore lies in this ring, and its determinant does too by the permutation formula. This puts each δℓ in a set whose spacing we can control.

Separation of algebraic integers. Let τ range over one embedding from each of the f conjugate pairs of the CM field E. For distinct x, y in 𝒪E, the product ∏τ|τ(x) − τ(y)|² equals |NmE/ℚ(x − y)| ≥ 1. Indeed the norm multiplies all conjugates, and each conjugate pair contributes a squared modulus. Multiplication by the nonzero algebraic integer x − y on the integral lattice 𝒪E has nonzero integral determinant. This also covers units, whose absolute norm equals one.

Divide each complex plane into half-open squares of side ½. Two points in the same square differ by less than 1 in modulus. If two algebraic integers occupied the same square at every place, their product of squared differences would be less than 1. Thus a choice of one square at each place contains at most one algebraic integer.

Counting at a fixed size

Let d be the root discriminant of E and H₁ the positive height scale of the fixed-list estimate. For a minor of order ℓ set eℓ = ∑a=1ℓ(r + 1 − a), ρℓ = d2eℓ(2H₁)2r and Rℓ = max(1, ρℓ). At place τ the size of a list is στ = max(1, max1≤ℓ≤j |τ(δℓ)|/ρℓ). Its global size is S = ∏τστ. Different places can attain their maxima at different minors.

Record the integer aτ for which 2aτ ≤ στ < 2aτ+1. Write A = ∑τaτ. Fixing these integers places τ(δℓ) in a disk of radius 2aτ+1Rℓ. Each real or imaginary coordinate in that disk meets at most 8·2aτRℓ + 2 ≤ 10·2aτRℓ half-unit intervals. Multiply the choices for two coordinates, for all places, and then for the j positions. By separation, the resulting bound on the number of distinct lists with this profile is Bj22jA, where Bj = ∏ℓ=1j(10Rℓ)2f. Counting every possible combination of entries gives an upper bound even when only a few combinations are realized by flags.

Shell bound. Let Nj(h) count the realized lists with 2h ≤ S < 2h+1. Multiplying the local inequalities gives 2A ≤ S < 2A+f, so A ≤ h ≤ A + f − 1. For an upper bound it suffices to include every profile with A ≤ h. There are exactly binom(h + f, f) nonnegative profiles with this property. To see this, put the unused h − A in a final slot and choose the positions of f separators among h + f symbols. This gives

Nj(h) ≤ binom(h + f, f) · Bj · 22jh   (h ≥ 0).

A list may have zero entries. In this one-place experiment, fix a single nonzero entry x in the Gaussian integers and take unit radius, so S = max(1, |x|). The shell 2 ≤ S < 4 contains 36 possible entries. For |x| < 4, the vertical lines with real part 0, ±1, ±2 and ±3 contain respectively 7, 14, 14 and 10 points in total. The smaller disk |x| < 2 contains 9, including the origin. The origin cancels in the difference 45 − 9 = 36. Any realization condition on the minor can only reduce this count.

What changes if the list has two entries? With the same unit radii, count ordered Gaussian pairs (δ₁, δ₂) with δ₂ ≠ 0. Inside the outer disk there are 45 choices for δ₁, including zero, and 44 for δ₂. Inside the smaller disk there are 9 and 8. Subtraction gives 45·44 − 9·8 = 1,908 candidates in the shell. One large coordinate already places a pair in the shell. In the general dimension argument, the bound for each shell is multiplied by the bound for one list before summing the diagonal error.

Two places can select different minors. Take E = ℚ(ζ₈) = ℚ(√2, i), with ζ₈ a primitive eighth root of unity. Its absolute discriminant is 2⁸ by the prime-power cyclotomic discriminant formula, so its root discriminant is d = (2⁸)1/4 = 4. Take r = j = 2 and H₁ = 1. The exponents are e₁ = 2 and e₂ = 2 + 1 = 3. The corresponding radii are ρ₁ = 4⁴ · 2⁴ = 4096 and ρ₂ = 4⁶ · 2⁴ = 65536. J. S. Milne, Algebraic Number Theory, Proposition 6.2(a,d).

Put α = 3 + 2√2 and β = 3 − 2√2, so αβ = 1. Consider the two integral minors x = ρ₁α and y = ρ₂β. For example, the matrix with rows (x, 1) and (−y, 0) has first leading minor x and determinant y. Adding an integer multiple of the first row to the second preserves both. All these matrices give one candidate list in the count. Realization by a pair of flags imposes the additional geometric conditions.

Why the remaining power pays for every list

Each list in a profile of total A has weight S−3r ≤ 2−3rA. Put κ = 3r − 2j ≥ r ≥ 1. The whole profile contributes at most Bj2−κA. For the shell bound we allowed every profile of total at most h. Here each list returns to its unique profile. Put x = 2−κ. With A fixed, inserting f − 1 dividers among A identical marks gives exactly binom(A + f − 1, f − 1) possible profiles. We may allow BjxA for each, including profiles that contain no realized list. Summing the factors xA with these multiplicities gives (1 − x)−f, since the product of f geometric series makes one independent choice per place. This accounts for the multiplicity of profiles in the weighted count. In particular, every finite set T of distinct realized lists satisfies

∑δ∈T S(δ)−3r ≤ Bj(1 − 2−κ)−f ≤ 2j ∏ℓ=1j(64Rℓ)2f.

The last inequality follows from (1 − 2−κ)−1 ≤ 2 and j ≥ 1. The bound is independent of T, so taking the supremum over finite subsets also bounds the full nonnegative sum. Under the standing scale assumptions b = exp(L), L > 1, log d ≤ L/Cl, Cl ≥ 1, r ≤ m and H₁ = bCHm, the arithmetic scale comparison bounds the right-hand side by bCc²m²fr with Cc = 21 + 4|CH|. To check the scale, use eℓ ≤ r² and log 2 < L. They give log Rℓ/L ≤ 2r² + 2r(1 + |CH|m). After taking logarithms to base b, the bound for the weighted sum costs at most

j + 2fj[6 + 2r² + 2r(1 + |CH|m)] ≤ (21 + 4|CH|)m²fr.

Here j ≤ r ≤ m and f ≥ 1. Since Cc ≥ 1, this fits inside the stated allowance Cc²m²fr.

Why does the ideal norm cost only the square of the size?

The count bounds a sum of weights in S. The amplitude also contains the normalized ideal norm Δ of the last minor. To put these two quantities on the same scale, fix the real subfield F of E and write DF, DE for their absolute discriminants. Then [E : F] = 2, [F : ℚ] = f and d2f = DE. At order ℓ, put e = eℓ and x = δℓ. The word gives x through its two flags. The ideal used to normalize it is fixed by the fields. It is 𝔞 = 𝔇F/ℚ𝒪E, the extension to E of the different of F. For x ≠ 0, let Δℓ be the absolute norm of the fractional ideal (x)𝔞−2e. Set Δℓ = 0 when x = 0.

The norm of the different of F is DF. Extending an ideal to E squares its absolute norm, since 𝒪E is locally free of rank two over 𝒪F. Thus Nm(𝔞) = DF². For x ≠ 0, the principal ideal has norm ∏τ|τ(x)|². Multiplicativity gives Δℓ = DF−4e ∏τ|τ(x)|². Put Mτ = |τ(x)|/d2e. Removing this power of d at every place brings out the ratio of discriminants. A. Sutherland, Number Theory I, Lecture 6, Remark 6.13 · Lecture 12, Theorem 12.17 and Proposition 12.27.

Δℓ = (DE/DF²)2e · (∏τ Mτ)².

The arithmetic family satisfies DE = DF². At each place the maximum defining στ includes Mτ/(2H₁)2r whenever x ≠ 0. Multiplying gives √Δℓ ≤ (2H₁)2rfS. A zero intermediate minor has norm zero and satisfies the squared inequality as well. The amplitude also uses an inverse power of Δ = Δj. For that step we need to know why the last minor is nonzero.

Why the last minor is nonzero. Let X and X′ be the two totally isotropic spaces in the flags. Thus the Hermitian pairing vanishes on each space separately. Write I = X ∩ X′, and let U and U′ be the spans of the first j frame vectors on each side. The normal-form theorem for a surviving term gives U ∩ I = 0 and X′ = U′ + I. It also relates the last frame vectors z and z′. Each is orthogonal to its own isotropic space, and z′ − cz lies in X + X′ for some nonzero scalar c in E. We use one more flag hypothesis. Every isotropic vector orthogonal to both X′ and z′ belongs to X′. In the arithmetic flags, a vector outside X′ meeting these orthogonality conditions has strictly positive squared length at the chosen infinite place.

If δj vanished, a nontrivial linear combination of the first j rows of the pairing matrix would be zero. The corresponding combination of frame vectors gives a nonzero x in U, because those vectors are independent. The zero row says that x is orthogonal to U′. It is already orthogonal to all of X, including I. The decomposition of X′ now gives x orthogonal to X′ as well. Since x is orthogonal to z and to z′ − cz, it is orthogonal to z′. Finally x is isotropic since it lies in X. The flag hypothesis places it in X′, so x belongs to U ∩ I = 0. This contradiction proves δj ≠ 0. Its normalized ideal norm is therefore positive.

0 < Δ ≤ (2H₁)4rf S² ≤ bCm²f S².

For the last step use H₁ = bCHm, b ≥ 2, CH ≥ 0 and m = 2r + 2. Then 2H₁ ≤ bCHm+1, while 4r ≤ 2m and CHm + 1 ≤ (CH + 1)m. Any C ≥ 2(CH + 1) works for every word and every defect. In the fixed-list estimate the ideal factor is Δ(j+1)/2. Raising the bound to this power costs precisely Sj+1.

A zero before the last position. Consider two isotropic planes with bases (e₁, e₂) and (f₁, f₂). Pair e₁ with f₁ and e₂ with f₂ with value 1, and give the other two pairs value 0. Read the second basis in the order (f₂, f₁). The resulting matrix has rows (0, 1) and (1, 0). Its list of leading determinants is (0, −1). The zero occupies the first slot in the shell count, while the inverse power in the amplitude applies to the second slot.

Checking the field hypothesis. Set r = j = f = 2 and H₁ = 1. Take the candidate list (ρ₁, ρ₂), so both normalized entries equal one at each place, S = 1 and e₂ = 3. In ℚ(ζ₁₂) with real subfield ℚ(√3), the discriminants are 144 and 12. Here d = √12 and ρ₂ = 16 · 12³. Directly from the ideal norm, Δ = (16 · 12³)⁴/144⁶ = 2¹⁶. This attains (2H₁)4rf exactly. In the shell example over ℚ(ζ₈) the real subfield ℚ(√2) has discriminant 8, so DE/DF² = 256/64 = 4. With the same choice (ρ₁, ρ₂) for this field, Δ = 65536⁴/64⁶ = 2²⁸. The extra factor is 4⁶ = 2¹², exactly as in the product formula. The shell count uses the spacing of integers in either field. The sharper ideal-norm bound uses the family’s discriminant identity.
