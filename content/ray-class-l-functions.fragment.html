Continuation, zero-free region and Landau–Page uniqueness without a functional equation

Why can the analytic properties of the ray-class L-functions invoked in the short-interval norm-prime theorem above—holomorphic continuation into the critical strip, nonvanishing and logarithmic differentiation on Re s > 1, the classical logarithmic zero-free region, and Landau–Page uniqueness of at most one real exceptional zero—be established without proving a Hecke functional equation, root numbers, or gamma factors, and even without factoring the series into an Euler product? Two elementary mechanisms replace both. First, subtracting the linear main term from the ideal-counting sum in each ray class leaves a square-root remainder O(√x), so Mellin integration by parts continues (s − 1)𝟏χ=1L(s, χ) holomorphically to Re s > 1/2 with quadratic polynomial growth in ‖s‖; on concentric discs centered at 5/4 + it, that polynomial bound suffices for Jensen’s zero count and the Borel–Carathéodory logarithmic-derivative expansion. Second, the group-ring convolution identity (a log) = λ ∗ a integrates on Re s > 1 to express each L-series directly as an exponential of prime-power weights, and nonnegativity of the class weights λ(g, n) ≥ 0 supplies both a uniform lower bound at 5/4 + it and the trigonometric and four-character positivity inequalities that repel zeros from Re s = 1.

To state all three analytic inputs uniformly, let G be a finite abelian group written additively with identity 0 ∈ G and character group Ĝ = Hom(G, ℂ×), where χ = 1 denotes the trivial character χ(g) = 1 and (χψ)(g) = χ(g)ψ(g). Fix a scale parameter B ≥ 4 and a local class density κ ∈ [1/B, 4] (denoting here the ideal-count density per class of G, distinct from the global relative-error parameter of Chapters 2, 7 and 9) with |G| ≤ B, together with two nonnegative sequences a, λ : G × ℕ → ℝ≥0 satisfying five axioms:

|∑1≤n≤x a(g, n) − κx| ≤ 10√x  (x ≥ 1),   |∑n≥1 a(g, n) e−tn − κ/t| ≤ B10t  (0 < t ≤ 1),   a(g, n) log n = ∑h∈G ∑pq=n λ(h, p)a(g − h, q),

supplemented by the normalization a(g, 0) = 0 for all g ∈ G, a(0, 1) = 1 and a(g, 1) = 0 for g ≠ 0, the von Mangoldt dominance ∑g∈G λ(g, n) ≤ 2Λ(n) for all n ≥ 0, and real-character convolution positivity: for every real character χ ∈ Ĝ (meaning χ² = 1) and every n ≥ 0, the Dirichlet convolution of b1(p) = ∑g∈G a(g, p) with bχ(q) = ∑g∈G (Re χ(g))a(g, q) satisfies ∑pq=n b1(p)bχ(q) ≥ 0 and ∑pq=n² b1(p)bχ(q) ≥ b1(n). The ray class group G of K = ℚ(√(−d)) modulo M𝒪K (for prime d ≡ 3 modulo 4 with d ≥ 100 and integer M ≥ 3) satisfies all five axioms at B = 4dM² ≥ 3600 and κ = 2π/(√d M²) ∈ [1/B, 4], with a(g, n) and λ(g, n) counting integral ideals and prime-power ideals of norm n coprime to M in class g, and quadratic convolution positivity coming from the nonnegative Euler-factor coefficients of ζK(s)L(s, χ). For each χ ∈ Ĝ, define the twisted coefficients aχ(n) = ∑g∈G χ(g)a(g, n) and λχ(n) = ∑g∈G χ(g)λ(g, n), the Chebyshev sum ψ(χ, u) = ∑1≤n≤u λχ(n), the residue ρχ = κ|G| when χ = 1 and ρχ = 0 when χ ≠ 1, the Mellin remainder integral M(χ, s) = ∫₁∞ (∑1≤n≤x aχ(n) − ρχx)x−s−1 dx, the regularized continuation F(χ, s) = ρχs + (s − 1)sM(χ, s) when χ = 1 and F(χ, s) = sM(χ, s) when χ ≠ 1, and the conductor-height weight ℓ(t) = log(B(|t| + 2)) > 2.

Theorem (Analytic continuation, zero-free region and Landau–Page uniqueness). For every finite-group L-family as above and every χ ∈ Ĝ, the function F(χ, s) is holomorphic on Re s > 1/2, agrees with (s − 1)𝟏χ=1 ∑n≥1 aχ(n)n−s on Re s > 1, satisfies ‖F(χ, s)‖ ≤ 300B(‖s‖ + 1)² on Re s ≥ 11/20, obeys Schwarz symmetry F(χ, s̄) = conj(F(χ, s)) whenever χ² = 1, and on Re s > 1 satisfies F(χ, s) ≠ 0 together with −F′(χ, s)/F(χ, s) + 𝟏χ=1/(s − 1) = ∑n≥1 λχ(n)n−s. Moreover, there exist absolute constants c₁ > 0 and c₂ > 0 such that across every finite-group L-family:

Re s ≥ 3/4,   F(χ, s) = 0,   (χ² ≠ 1 or Im s ≠ 0)  ⇒  Re s < 1 − c₁ / ℓ(Im s),

and whenever χ, ψ ∈ Ĝ satisfy χ² = ψ² = 1 and β, β′ ∈ ℝ satisfy β, β′ ≥ max(3/4, 1 − c₂/ℓ(0)) with F(χ, β) = F(ψ, β′) = 0, one has χ = ψ, β = β′, and F′(χ, β) ≠ 0.

Proof. By character orthogonality ∑g∈G χ(g) equals |G| when χ = 1 and 0 when χ ≠ 1, so summing the counting bound over g ∈ G gives ‖∑1≤n≤x aχ(n) − ρχx‖ ≤ 10|G|√x ≤ 10B√x for all x ≥ 1. Hence M(χ, s) converges holomorphically on Re s > 1/2 and satisfies ‖M(χ, s)‖ ≤ 10B ∫₁∞ x−11/20−1/2 dx = 200B on Re s ≥ 11/20. Abelian summation on Re s > 1 identifies F(χ, s) = (s − 1)𝟏χ=1L(aχ, s), while ρ1 = κ|G| ≤ 4B gives ‖F(χ, s)‖ ≤ 4B‖s‖ + 200B‖s‖(‖s‖ + 1) ≤ 300B(‖s‖ + 1)² on Re s ≥ 11/20; when χ² = 1, every value χ(g) lies in {±1} ⊂ ℝ, so aχ(n) ∈ ℝ and F(χ, s̄) = conj(F(χ, s)). Next, multiplying the convolution axiom by χ(g) = χ(h)χ(g − h) and summing over g ∈ G yields (aχ log) = λχ ∗ aχ with aχ(1) = χ(0)a(0, 1) = 1 and ‖λχ(n)‖ ≤ ∑g∈G λ(g, n) ≤ 2Λ(n). On Re s = σ > 1, this Dirichlet convolution identifies L(aχ, s) = exp(∑n≥2 (λχ(n)/log n)n−s); comparing the real part of the exponent with R = ∑n≥2 (Λ(n)/log n)n−σ = log ζ(σ) ≤ log(σ/(σ − 1)) gives ‖L(aχ, s)‖ ≥ e−2R ≥ ((σ − 1)/σ)² > 0, whence F(χ, s) ≠ 0 and −F′(χ, s)/F(χ, s) + 𝟏χ=1/(s − 1) = L(λχ, s).

For any real height t, the closed disc B̄(c, 7/10) around c = 5/4 + it lies inside {Re w ≥ 11/20}, where ‖F(χ, w)‖ ≤ 300B(‖w‖ + 1)², while at the center c one has ‖F(χ, c)‖ ≥ |c − 1|𝟏χ=1((5/4 − 1)/(5/4))² ≥ 1/100. Dividing out the finite Blaschke product of zeros on the concentric subdisc ‖w − c‖ ≤ 3/5 (relative radius 6/7 < 1) and applying Borel–Carathéodory and Cauchy’s derivative estimate on ‖s − c‖ ≤ 1/2 (relative radius 5/7 < 6/7) yields an absolute constant C > 0 such that F(χ, ·) has at most Cℓ(t) zeros w (counted with multiplicity) in ‖w − c‖ ≤ 3/5, and for every s in ‖s − c‖ ≤ 1/2 away from those zeros, ‖F′(χ, s)/F(χ, s) − ∑‖w−c‖≤3/5 ordw(F(χ, ·))/(s − w)‖ ≤ Cℓ(t). Because every remaining zero w satisfies Re w ≤ 1 < σ for σ ∈ (1, 5/4], its neglected partial-fraction term has positive real part, so Re L(λψ, σ + it) ≤ 𝟏ψ=1 Re(1/(σ − 1 + it)) − ∑w∈S Re(1/(σ + it − w)) + Cℓ(t) for any subset S of zeros (with multiplicity) in ‖w − (5/4 + it)‖ ≤ 3/5. Meanwhile, nonnegativity λ(g, n) ≥ 0 gives four inequalities for σ > 1 and t ∈ ℝ: (i) 3 Re L(λ₁, σ) + 4 Re L(λχ, σ + it) + Re L(λχ², σ + 2it) ≥ 0 from 3 + 4 Re z + Re(z²) = 2(1 + Re z)² ≥ 0 on |z| = 1; (ii) Re L(λ₁, σ) ≥ 0; and for real characters χ² = ψ² = 1, (iii) Re L(λ₁ + λχ, σ) ≥ 0 and (iv) Re L(λ₁ + λχ + λψ + λχψ, σ) ≥ 0 from 1 + χ(g) ≥ 0 and (1 + χ(g))(1 + ψ(g)) ≥ 0. Testing (ii) (when χ = 1) or (iii) (when χ ≠ 1) at σ = 1 + 60ε when χ² = 1 and 0 < (Im s)² < (30ε)² (pairing s with its distinct conjugate zero s̄), testing (i) at σ = 1 + 6ε in all remaining cases of the zero-free region, and testing (ii)–(iv) at σ = 1 + 2c₂/ℓ(0) for two real zeros or a multiple real zero near 1 completes both claims.

Euler-product-free exponential identity, conjugate-zero pairing and four-character Landau–Page test

On Re s > 1, define G(s) = ∑n≥2 (λχ(n)/log n)n−s, which converges absolutely with G′(s) = −L(λχ, s) because ‖λχ(n)‖ ≤ 2Λ(n). Termwise differentiation and Dirichlet multiplication give (d/ds)[L(aχ, s) exp(−G(s))] = [−L(aχ log, s) + L(λχ, s)L(aχ, s)] exp(−G(s)) = 0 since aχ log = λχ ∗ aχ. As Re s → +∞ along the real axis, L(aχ, s) → aχ(1) = 1 and G(s) → 0, so L(aχ, s) = exp(G(s)) everywhere on Re s > 1.

Suppose now that F(χ, s) = 0 with s = 1 − δ + iγ, Re s ≥ 3/4, and either χ² ≠ 1 or γ ≠ 0. Nonvanishing on Re s > 1 gives δ ≥ 0, and if δ > 1/400 then δ > (1/800)/ℓ(γ) because ℓ(γ) > 2. Assume 0 ≤ δ ≤ 1/400 and fix any ε ∈ (0, 1/400] with δ ≤ ε. If χ² = 1 and 0 < γ² < (30ε)², Schwarz symmetry gives the distinct zero s̄ = 1 − δ − iγ, and both s, s̄ lie inside B̄(5/4, 3/5) because (1/4 + δ)² + γ² ≤ (101/400)² + (3/40)² < (3/5)². Evaluating 0 ≤ Re L(λ₁, 1 + 60ε) (when χ = 1) or 0 ≤ Re L(λ₁, 1 + 60ε) + Re L(λχ, 1 + 60ε) (when χ ≠ 1) yields 2(60ε + δ)/((60ε + δ)² + γ²) ≤ 1/(60ε) + 2Cℓ(0); since (60ε + δ)² + γ² < (61ε)² + (30ε)² = 4621ε² and 120/4621 − 1/60 = 2579/277260 > 1/108, we obtain 1/(108ε) ≤ 2Cℓ(0) ≤ 2Cℓ(γ). Otherwise either χ² ≠ 1 or γ² ≥ (30ε)², and applying 3 Re L(λ₁, 1 + 6ε) + 4 Re L(λχ, 1 + 6ε + iγ) + Re L(λχ², 1 + 6ε + 2iγ) ≥ 0 bounds the first pole by 3/(6ε) = (1/2)/ε, subtracts at least 4/(6ε + δ) ≥ (4/7)/ε from the zero s, while on |γ| ≥ 30ε any pole at s = 1 in the second term (when χ = 1) satisfies 4 Re(1/(6ε + iγ)) = 24ε/(36ε² + γ²) ≤ 24ε/(936ε²) = 4/(156ε) and any pole in the third term (when χ² = 1) satisfies Re(1/(6ε + 2iγ)) = 6ε/(36ε² + 4γ²) ≤ 6ε/(3636ε²) < 1/(156ε). Because ℓ(2γ) ≤ 2ℓ(γ), collecting errors gives (1/14 − 5/156)/ε = (43/1092)/ε ≤ 9Cℓ(γ), so 1/ε ≤ 300Cℓ(γ) in both cases; letting ε ↓ δ rules out δ = 0 and gives δ ≥ 1/(300Cℓ(γ)) > c₁/ℓ(γ) for c₁ = 1/(1200C + 800).

For Landau–Page uniqueness, set c₂ = 1/(100(C + 1)) and σ = 1 + 2c₂/ℓ(0) ∈ (1, 5/4]. Every real zero x ∈ [1 − c₂/ℓ(0), 1] lies in B̄(5/4, 3/5) and contributes ordx/(σ − x) ≥ ordx · ℓ(0)/(3c₂), while the pole at 1 of L(λ₁, σ) contributes ℓ(0)/(2c₂). If χ = ψ and either β ≠ β′ or ordβ(F(χ, ·)) ≥ 2, the real-zero multiplicity is at least 2, so testing Re L(λ₁, σ) ≥ 0 (when χ = 1) or Re L(λ₁ + λχ, σ) ≥ 0 (when χ ≠ 1) yields 2ℓ(0)/(3c₂) ≤ ℓ(0)/(2c₂) + 2Cℓ(0), contradicting 1/(6c₂) > 2C. If χ ≠ ψ with χ² = ψ² = 1, testing Re L(λ₁ + λψ, σ) ≥ 0 when χ = 1, Re L(λ₁ + λχ, σ) ≥ 0 when ψ = 1, or Re L(λ₁ + λχ + λψ + λχψ, σ) ≥ 0 when χ, ψ ≠ 1 (where (χψ)² = 1 and χψ ≠ 1 since χ ≠ ψ) again pits at least 2ℓ(0)/(3c₂) from the zeros of χ and ψ against the single pole ℓ(0)/(2c₂) plus 4Cℓ(0), contradicting 1/(6c₂) > 4C.

Siegel-free polynomial repulsion at s = 1 via the positive Bessel kernel

Why does a real ray-class character χ of an imaginary quadratic field escape Siegel’s ineffectivity at s = 1, whereas an arbitrary real Dirichlet character modulo q admits only an ineffective lower bound L(1, χ) ≫ q−ε? Because the Dirichlet convolution b1 ∗ bχ of the total norm-counting sequence b1(n) = ∑g∈G a(g, n) with a real ray-class character sequence bχ(n) = aχ(n) has nonnegative coefficients for every n ≥ 1 and equals 1 at n = 1. Instead of meromorphically continuing the product L-function across the critical strip via a functional equation, one pairs the two Laplace transforms θ1(v/w) and θχ(w) against the scale-invariant measure dw/w on (0, ∞). Termwise change of variables turns every product exp(−vm/w − qw) into the positive modified Bessel integral W(vmq), bounding the paired integral uniformly below by W(1) > 0 for all 0 < v ≤ 1, while isolating the polar main term ρ1w/v of θ1(v/w) at an explicit polynomial scale v ≍ B−44 forces F(χ, 1) ≥ c₃/B45; Cauchy’s derivative estimate near s = 1 then converts that value bound into a completely effective polynomial zero repulsion 1 − β ≥ c₄/B46.

Theorem (Effective lower bound at s = 1 and real-zero repulsion). There exist absolute constants c₃ > 0 and 0 < c₄ ≤ 1 such that for every finite-group L-family (with scale B ≥ 4, class density κ ∈ [1/B, 4], and |G| ≤ B), every real character χ ∈ Ĝ satisfying χ² = 1, and every real zero β ≥ 3/4 of F(χ, ·),

‖F(χ, 1)‖ ≥ c₃ / B45,   1 − β ≥ c₄ / B46.

Proof. When χ = 1, evaluating F(1, s) = ρ1s + (s − 1)sM(1, s) at s = 1 gives F(1, 1) = κ|G| ≥ 1/B ≥ 1/B45 because B ≥ 4 and |G| ≥ 1. Suppose now that χ ≠ 1 with χ² = 1, so χ(g) = Re χ(g) ∈ {±1}, bχ(n) = aχ(n) ∈ ℝ, and |bχ(n)| ≤ b1(n). Form the Laplace series θ1(t) = ∑n≥1 b1(n)e−tn and θχ(t) = ∑n≥1 bχ(n)e−tn for t > 0. Summing the small-t Laplace axiom over |G| ≤ B classes for 0 < t ≤ 1 and applying partial summation from the counting bound for t ≥ 1 gives an absolute constant C₀ > 0 such that |θ1(t) − ρ1/t| ≤ C₀B11 min(t, 1/t) and |θχ(t)| ≤ C₀B11 min(t, 1/t) for all t > 0, with |θχ(t)| ≤ C₀Be−t/2 on t ≥ 1 and ∫₀∞ θχ(w) dw = F(χ, 1) ∈ ℝ.

Define the positive Bessel kernel W(y) = ∫₀∞ exp(−y/w − w) dw/w for y > 0, which is strictly positive, decreasing in y, satisfies W(y) ≤ 12/y³ via e−y/w ≤ 6(w/y)³, and takes a positive value w₀ = W(1) > 0 at y = 1. For any 0 < v ≤ 1, substituting w = u/q in each term (m, q) expands ∫₀∞ θ1(v/w)θχ(w) dw/w = ∑n≥1 (b1 ∗ bχ)(n)W(vn). By real-character convolution positivity, (b1 ∗ bχ)(n) ≥ 0 for all n ≥ 1, while the normalization axiom gives b1(1) = bχ(1) = 1 and hence (b1 ∗ bχ)(1) = 1. Dropping all terms n ≥ 2 and using monotonicity W(v) ≥ W(1) = w₀ yields w₀ ≤ ∫₀∞ θ1(v/w)θχ(w) dw/w. Conversely, splitting θ1(v/w) = ρ1w/v + (θ1(v/w) − ρ1w/v) and bounding |θ1(u) − ρ1/u| ≤ E√u (since min(u, 1/u) ≤ √u) and |θχ(w)| ≤ E min(w, 1/w) with E = C₀B11 gives w₀ ≤ (ρ1/v)F(χ, 1) + E²√v K, where K = ∫₀∞ min(w, 1/w)w−3/2 dw = 8/3. Choosing v = s₀² with s₀ = δ₀/B22 and δ₀ = min(1, w₀/(2C₀²K)) > 0 makes 0 < v ≤ B−44 < 1 and E²√v K = C₀²Kδ₀ ≤ w₀/2, leaving w₀/2 ≤ (ρ1/s₀²)F(χ, 1) ≤ (4B/s₀²)|F(χ, 1)| (since ρ1 = κ|G| ≤ 4B), and hence |F(χ, 1)| ≥ (w₀δ₀²/8)/B45. Setting c₃ = min(1, w₀δ₀²/8) covers both χ = 1 and χ ≠ 1.

Finally, let β ≥ 3/4 be any real zero of F(χ, ·). Nonvanishing on Re s > 1 from the continuation theorem above forces β ∈ [3/4, 1] ⊂ B̄(1, 1/4). For every z ∈ B̄(1, 1/4), the closed disc B̄(z, 1/10) lies inside {Re w ≥ 13/20 ≥ 11/20, ‖w‖ ≤ 27/20}, where (‖w‖ + 1)² ≤ (47/20)² < 6 and ‖F(χ, w)‖ ≤ 1800B; Cauchy’s derivative inequality on radius 1/10 therefore bounds ‖F′(χ, z)‖ ≤ 18000B on [β, 1]. By the mean-value inequality, c₃/B45 ≤ ‖F(χ, 1) − F(χ, β)‖ ≤ 18000B(1 − β), proving 1 − β ≥ c₄/B46 with c₄ = min(1, c₃/18000) ∈ (0, 1], which supplies the effective parameter δ = c₄/B46 used in the short-interval count.

Large-time Laplace decay and the Mellin evaluation at s = 1

Write Aχ(x) = ∑1≤n≤x aχ(n), so Aχ(x) = 0 for x < 1 and ‖Aχ(x) − ρχx‖ ≤ 10B√x for x ≥ 1; in particular ‖Aχ(x)‖ ≤ 4Bx + 10B√x ≤ 14Bx for x ≥ 1. For every t > 0, partial summation expresses θχ(t) = t ∫₁∞ Aχ(x)e−tx dx. When t ≥ 1, substituting x = 1 + u bounds ‖θχ(t)‖ ≤ 14Bte−t ∫₀∞ (1 + u)e−tu du = 14B(1 + 1/t)e−t ≤ 28Be−t/2, and since ‖ρχ‖/t ≤ 4B/t ≤ 4B11/t while e−t/2 ≤ 2/t, one gets ‖θχ(t) − ρχ/t‖ ≤ (56 + 4)B11/t = 60B11/t as well. When 0 < t ≤ 1, summing the second axiom over g ∈ G with χ(g) gives ‖θχ(t) − ρχ/t‖ ≤ |G|B10t ≤ B11t.

For χ ≠ 1 (so ρχ = 0), the bounds |θχ(t)| ≤ C₀B11t on (0, 1] and |θχ(t)| ≤ C₀Be−t/2 on [1, ∞) make θχ integrable on (0, ∞). Since ∫₀∞ t ‖Aχ(x)‖ e−tx dt = ‖Aχ(x)‖ x−2 ≤ 10Bx−3/2 is integrable on [1, ∞), Fubini’s theorem gives ∫₀∞ θχ(t) dt = ∫₁∞ Aχ(x) (∫₀∞ te−tx dt) dx = ∫₁∞ Aχ(x)x−2 dx = M(χ, 1) = F(χ, 1).

Truncated Perron contour shift and the explicit formula with an exceptional zero

Why can the explicit formula for ψ(χ, u) = ∑1≤n≤u λχ(n) extract the principal pole u and an optional exceptional-zero term −uβ/β with remainder O(u exp(−c√(log u))), without continuing F(χ, s) across Re s = 1/2 or summing over infinitely many critical-strip zeros? Instead of shifting across the entire strip, one shifts only into the narrow half-width zero-free corridor Re s ≥ 1 − c₀/(2ℓ(Im s)), which stays strictly inside the local 1/2-disc around 5/4 + i Im s at every height |t| ≤ T = exp(δ√(log u)). Within that corridor, every non-exceptional zero in the local 3/5-disc lies at distance ≫ 1/ℓ(Im s), bounding F′/F minus the single optional pole 1/(s − β) by O(ℓ(Im s)²). Because at most one exceptional zero β exists, a two-line pigeonhole choice inside [1 − 4d, 1 − 2d] at step d = c₀/(8ℓ(T)) selects a left vertical abscissa σ₁ separated from β by at least d; whether β falls inside the contour rectangle (contributing its residue −uβ/β) or to the left of σ₁ (where uβ/β is already O(u1−2d) and absorbed into the boundary integral), the contour closes with a de la Vallée Poussin saving.

Fix c₀ ∈ (0, 1/20]. For a character χ ∈ Ĝ, say that a finite set Z ⊂ ℝ is a c₀-admissible exceptional zero set for χ when |Z| ≤ 1, every β ∈ Z satisfies 1 − c₀/ℓ(0) ≤ β < 1, F(χ, β) = 0 and F′(χ, β) ≠ 0, and every zero w ∈ ℂ of F(χ, ·) satisfying Re w ≥ 1 − c₀/ℓ(Im w) belongs to Z. By the zero-free region and Landau–Page theorem, choosing c₀ = min(c₁, c₂, 1/20) equips every χ ∈ Ĝ with such a set Z (empty unless χ² = 1 and F(χ, ·) vanishes on [1 − c₀/ℓ(0), 1), and across all χ ∈ Ĝ at most one character has Z ≠ ∅).

Theorem (Explicit formula with an optional exceptional zero). For every c₀ ∈ (0, 1/20], there exist constants c > 0 and C > 0 (depending only on c₀) such that for every finite-group L-family (with scale B ≥ 4), every χ ∈ Ĝ, every c₀-admissible exceptional zero set Z ⊂ ℝ for χ, and every real u ≥ 2 satisfying log B ≤ √(log u),

‖ψ(χ, u) − 𝟏χ=1 u + ∑β∈Z uβ / β‖ ≤ C u exp(−c√(log u)).

Proof. First, on the half-width strip 1 − c₀/(2ℓ(Im s)) ≤ Re s ≤ 3 away from Z, one has ‖F′(χ, s)/F(χ, s) − ∑β∈Z 1/(s − β)‖ ≤ C₂ℓ(Im s)² for a constant C₂ > 0 depending only on c₀: on Re s ≥ 5/4 this follows directly from ‖L(λχ, s)‖ ≤ −2ζ′(5/4)/ζ(5/4) together with |s − 1|, |s − β| ≥ 1/4, while on 1 − c₀/(2ℓ(Im s)) ≤ Re s ≤ 5/4 (which lies inside B̄(5/4 + i Im s, 1/2) because c₀/(2ℓ(Im s)) < 1/80), every zero w ∉ Z in B̄(5/4 + i Im s, 3/5) obeys Re w < 1 − c₀/ℓ(Im w) ≤ 1 − 3c₀/(4ℓ(Im s)) and hence |s − w| ≥ c₀/(4ℓ(Im s)), so the at most C₁ℓ(Im s) non-exceptional local zeros contribute at most (4C₁/c₀)ℓ(Im s)². Second, because ‖λχ(n)‖ ≤ 2Λ(n), integrating along σ₀ = 1 + 1/log u for any 2 ≤ T ≤ u gives the truncated Perron approximation ‖ψ(χ, u) − (1/(2π)) ∫−TT L(λχ, σ₀ + it)(uσ₀+it/(σ₀ + it)) dt‖ ≤ C₃(u(log u)²/T + log u).

Set W = √(log u) and δ = c₀/32. When δW ≤ 1, the Chebyshev bound ‖ψ(χ, u)‖ ≤ 2∑1≤n≤u Λ(n) ≤ 4u and |uβ/β| ≤ 2u (as β ≥ 1 − c₀/ℓ(0) > 1/2) give ‖ψ(χ, u) − 𝟏χ=1u + ∑β∈Z uβ/β‖ ≤ 7u ≤ 7e1/2u exp(−(δ/2)W). Assume now δW ≥ 1 and put T = exp(δW) ∈ [2, u]. Since log B ≤ W, we have ℓ(T) = log B + log(T + 2) ≤ 3W. Put d = c₀/(8ℓ(T)). Because |Z| ≤ 1, setting σ₁ = 1 − 2d when Z = ∅ or β ≤ 1 − 3d, and σ₁ = 1 − 4d when β > 1 − 3d, places σ₁ ∈ [1 − 4d, 1 − 2d] with |σ₁ − β| ≥ d for every β ∈ Z, while ℓ(t) ≤ ℓ(T) keeps σ₁ ≥ 1 − c₀/(2ℓ(t)) for all |t| ≤ T.
