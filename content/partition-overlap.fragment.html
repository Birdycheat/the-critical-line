Why this bump also works for the derivative estimate

Say k is δ-close to positive h if |qk(z)−qh(z)| ≤ δqh(z) for all archimedean columns. Polarization on coordinate vectors gives ‖k−h‖ ≤ 2δ‖h‖ in the matrix-entry norm. The smooth compactly supported ψ has an ordinary Lipschitz constant Lψ. Choose R ≥ 0 bounding the norm on K′. If the two values differ, at least one point belongs to K′. For 0 ≤ δ < ¼ the norm estimate then gives ‖h‖ ≤ 2R, so |ψ(k)−ψ(h)| ≤ 4LψRδ. For δ ≥ ¼ the bound 0 ≤ ψ ≤ 2/m supplies the upper bound 16δ/m. Thus Cψ = 16/m + 4LψR works for every δ ≥ 0, including cases where k lies outside the cone. Composing with the relative bounds for the normalization and correction, then differentiating in a moving frame, gives the one-power height bound.
