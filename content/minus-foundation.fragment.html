Why the Bernoulli factor is integral

To combine several primes in the minus estimate, the proof discards some character factors from an ℓ-adic product. This step is safe when each discarded factor has nonnegative valuation. Where does that integrality come from? At twist j put k = j + 1 ≥ 2. If χ has level N, conductor f and primitive character χ*, its denominator-cleared Bernoulli value is α = NPkBk,χ*, where Pk is the product of the primes at most k + 1. The two integer multipliers pay for different denominators. Normalization and conductor, Use of integrality in the valuation sum.

Expand the Bernoulli polynomial in ordinary Bernoulli numbers Bh. The rational coefficient attached to one residue a is

fk−1Bk(a/f) = ∑h=0k binom(k,h) Bh fh−1ak−h.

At h = 0 the factor f−1 can introduce a conductor denominator. Multiplying the entire sum by f changes every exponent to the nonnegative integer h. For a positive even h, the von Staudt–Clausen formula expresses Bh as an integer minus a sum of 1/p over primes with p−1 dividing h. Each such p is at most h+1 ≤ k+1, so it divides Pk. The remaining indices give B₀ = 1, B₁ = −½ and Bh = 0 for odd h > 1. Thus PkBh is integral throughout, and fPk times the displayed coefficient is an integer, residue by residue. Multiplying these integers by χ*(a) and summing keeps the result in the ring generated by the character values. A unit value is a root of unity, hence an algebraic integer, and a nonunit contributes zero. Each unit modulo f lifts to a unit modulo N, so the values of χ* belong to the ring generated by the original χ. Finally f divides N. Multiplying by the integer N/f proves the required integrality of α in that ring. The same scaling also allows a single archimedean bound. For k ≥ 2 the Fourier expansion on [0,1] pairs the positive and negative frequencies. Each pair of unit complex phases has absolute value at most 2. Its reciprocal-power sum is bounded by 2∑m≥11/m² = π²/3 < 4. Consequently |Bk(x)| ≤ 4k!/(2π)k. There are f terms in the primitive sum, each carrying fk−1 and a character value of absolute value at most 1. Using f ≤ N, Pk ≤ 4k+1 and 4/(2π) ≤ 1 gives |α| ≤ 16Nk+1k!. The denominator bound uses von Staudt–Clausen and the primorial estimate. The absolute-value bound uses the Fourier series and the sum of reciprocal squares. An odd character of conductor three

For j = 2, k = 3. Choose the quadratic character modulo 3, with values 1, −1, 0 on 1, 2, 3. It has the required odd parity. Since B₃(x) = x³ − 3x²/2 + x/2, its values at ⅓ and ⅔ are 1/27 and −1/27. Hence

B3,χ* = 3²(1/27 + 1/27) = 2/3,   L(−2,χ*) = −2/9,   α = (3·2·3)(2/3) = 12.

At ℓ = 3 this factor contributes log 3 to the upper bound from valuations. At every odd prime exceeding 3 it contributes zero. If the same primitive character is presented at level 6, the local factor is (6·2·3)(2/3) = 24. Directly evaluating the imprimitive Bernoulli sum at level 6 would instead multiply 2/3 by the extra Euler factor 1 − χ*(2)2² = 5, giving 10/3. This computation explains why the definition takes the clearing factor from the displayed level and the Bernoulli value from the conductor. These are upper-bound inputs for cohomological lengths.
